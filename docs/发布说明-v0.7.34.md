# Serylane v0.7.34

## 下载中心唯一来源

- 软件更新固定使用下载中心，移除渠道选择与备用下载说明。旧渠道偏好自动兼容迁移，不重置其他设置。
- 官网六个系统/架构下载入口只使用中心，继续区分 macOS Intel 与 Apple 芯片。
- 中心不可用、文件缺失、元数据不符或安装包校验失败时提示原因与重试；不回退其他站点、旧版或不同架构。
- 更新元数据与安装包请求拒绝重定向；保持版本、平台、大小、SHA-256、签名以及安装确认检查。下载过程保留有限重试、取消和当前代理。

## 文档与 TUN 方案

- 当前说明按源码修正：单节点可用但没有备用；程序代理、增强稳定策略与新增 Codex 接入当前停用；域名路由由 Mihomo 实现。
- README 与当前业务契约增加源码事实表，版本、能力门禁与节点范围变化后由测试提醒同步。
- 提供 TUN 三端稳定化方案：最小特权服务、资源归属恢复、签名发布及实机验收矩阵。本版未实现新的 TUN 服务，平台支持边界不变。

## 升级与验证范围

自动化验证涵盖更新状态、来源限制、签名安装事务与官网六架构选择；实际结果以对应提交的 CI 和发行门禁为准。历史标签与安装包不改写，旧 v0.7.24–v0.7.27 更新器安装受阻时仍需先从下载中心获取完整修复版。

本版不安装或重启当前用户应用，不改变正在使用的代理。Windows TUN 仍为实验性，macOS 兼容包仍不满足正式 TUN 签名身份，Linux TUN 尚未实现。源码提交、发行产物、下载中心归档与官网部署分别核验后才能确认上线。
