# Serylane v0.7.26

[文档索引](index.md) · [集中项目文档](https://github.com/CMMUU/project-docs/tree/main/serylane)

## macOS 内置更新修复

- `.app` 应用包使用独立完整性验证，修复备份阶段误报“非普通签名文件”。备份及替换后一起检查嵌套代码、资源、应用标识、启动入口和版本；不放宽普通文件或 TUN Developer ID 检查。
- 安装预检失败保留本次运行中已通过签名与 SHA-256 验证的包；处理问题后显示“重新安装”，再次核对版本、架构及摘要。校验不匹配的包不复用，退出应用后需重新下载。
- 磁盘预留考虑压缩包、已安装应用、备份和解压开销；预检与备份在停止代理之前完成。
- 开始停止/替换后不自动循环重试；工作线程持有事务锁，界面请求中断不提前释放锁，也不取消成功后的重启。
- 旧应用备份保持到新版进程启动且包完整性确认，才清理对应事务目录。替换失败尝试回退；回退未完成保留原始原因和恢复资料，不删除唯一旧副本。
- 安装收据升级为独立 v2 文件，兼容读取旧记录；预检失败也记录阶段、脱敏原因和是否已进入停止流程。

## 首次从旧版恢复

v0.7.24 / v0.7.25 的旧更新器会在执行修复代码之前卡在安装预检。请从下载中心获取本版完整安装包，退出旧版后覆盖原来的 Serylane.app，保留独立用户配置。后续升级再使用修复后的内置更新器。直接重下旧版或重新授权 TUN 不解决这条错误。

## 验收与边界

- 新增真实签名 `.app`、Tauri 下载验签/解包替换、回退和新进程版本验证；macOS Apple Silicon/Intel 发版还运行实际产物备份/替换验证。
- Windows NSIS/MSI 安装门禁及六平台回归保留。隔离测试不改变用户实际安装、订阅、代理、TUN 或 Codex 配置；真实用户原位升级和 OS 登录/重启独立记录。
- 兼容 macOS 包保留项目更新签名及代码完整性检查，不代表 Apple Developer ID、公证或 TUN 已就绪。
- Gitee 仍受平台对仓库内容的公开限制；下载中心与 GitHub 是当前公开来源，不把 Gitee 报为同步完成。
