## 下载与更新

- 唯一产品下载来源为 [下载中心](https://downloads.cmmuu.com/projects/serylane)。应用读取中心版本 API，官网六个系统/架构入口也只解析该中心。
- 旧设置中的自动、GitHub、Gitee 偏好迁移为下载中心；其他用户设置保留。旧线协议标识 hk 属于兼容数据，不是额外渠道。
- 元数据必须匹配版本、平台、架构、大小、摘要与签名；真实文件必须位于中心专属文件路径，不能通过下载重定向切换来源。中心不可用、未同步或文件不完整时提示失败和重试。
- 网络波动使用有界重试，下载可取消，完整性失败不安装。安装确认、原生预检、停止旧进程、替换与失败恢复仍独立执行；不因检查或下载变更当前代理。
- 源码仓库与发行归档是维护设施，不是用户下载备用渠道；历史已签名产物、标签和审计记录保持不变。

代码入口：`src-tauri/src/app_update.rs`、`app_update/transport.rs`、`app_update/transaction.rs`、`src/app-update.ts`、`website/src/worker.ts`。

## 当前代理业务

- Manual 仅提供本地端口；System Proxy 管理操作系统代理；TUN 能力按平台限定。主启动按钮沿用保存的模式。
- 自选节点保留原策略组；AI 代理运行候选筛选和基础 Fallback。至少一个合格候选可启用，只有一个时没有备用；无合格候选则拒绝生成，不突破预算兜底。
- 流量倍率由用户核实，未知费用单独处理。预算过滤作用于实际有效候选。增强稳定后台策略当前停用，不能将其历史设计写成已运行能力。
- 域名路由在 Mihomo 中生成高优先级工具域名规则，选定出口、保存与启用独立。读回核心规则确认生效，未运行或核对失败不能显示已生效。
- 新增 Codex 接入及程序代理被后端能力开关阻止，历史配置保留；旧接入仅按所有权检查恢复。不会重新启用本地 Responses 中继来掩盖网络问题。
- 401 只说明目标路径到达认证响应阶段；网站检测成功不代表真实模型会话或持续流已验证，切换节点无法无缝续接断流。

代码入口：`capabilities.rs`、`openai_policy.rs`、`effective.rs`、`domain_routing.rs`、`routing/`（均位于 `src-tauri/src/`）；前端状态不绕过后端门禁。

## 启动、订阅与日志

- 新安装默认不随登录启动；后台恢复选项保存后才注册登录项。静默仅控制窗口，恢复使用上次实际意图：之前运行则按原模式尝试恢复，之前停止则保持停止。
- 订阅配置下载与套餐用量刷新分别计时、记录状态；失败保留可用旧配置。连接与完整下载有时限，不通过静默切换系统代理处理超时。
- 应用日志默认保留 3 天，可设 1–90 天；正文最多 256 KiB / 2,000 条，容量达上限可提前淘汰。存储保持紧凑，展示按时间和级别格式化，不存储对话正文或订阅凭据。
- 核心状态查询不再创建版本探测进程；系统结束会话期间暂停新核心任务，取消关机后恢复。具体机器的登录、注销、关机和网络恢复需要独立实测。

## TUN 与验收

Windows 当前整应用提权且实验性；macOS 有 Helper，但兼容包不具备正式 TUN 签名身份；Linux 当前没有接管实现。完整方案见 [TUN 三端稳定化方案](TUN三端稳定化方案-2026-10-30.md)。

v0.7.35 在有效 TUN 配置中启用并校验内置 DNS，保留原始订阅。Windows 启动增加接口、路由与 DNS 的有界就绪检查；完成后独立检查外网，再次读回本地状态。外网最多 3 轮、共享 30 秒预算，仅重试可恢复的失败探测；TLS 握手中断与证书/协议错误区分处理，不降低 TLS 校验。持续失败仍回退，并区分失败阶段与恢复结果。

本版没有安装新的常驻特权服务、解决 macOS 签名身份或开放 Linux TUN。真实主机 TUN 切换、路由/DNS 恢复、休眠和长流尚需独立验收。实现、签名发布、原生集成测试和真实网络验收必须分别记录。
