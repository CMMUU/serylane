# Serylane v0.7.25

[文档索引](index.md) · [集中项目文档](https://github.com/CMMUU/project-docs/tree/main/serylane)

## AI 工具与自定义地址路由

- 路由从旧模型中转改为 Mihomo 域名规则，默认关闭，不再新增 Codex 接入。
- 常见 AI 工具可选 OpenAI（ChatGPT / API）、Claude、Gemini（网页 / AI Studio / API），后台展开相关域名。默认草稿只选择 OpenAI，展开可查看具体范围。
- 自定义地址单独编辑，支持根域、`*.example.com` 和 `https://*.example.com/*`；工具域名与自定义地址共用校验、去重、编译和应用流程。取消工具不删除自定义条目。
- 域名匹配覆盖全部 HTTPS/WSS 路径，不解密 TLS；共享第三方登录、支付与公共资源不自动整域纳入。
- 保存草稿不改变流量；应用需单独确认策略组和范围。路由优先于本地、AI 与订阅规则，其余流量保持原规则。切换订阅导致目标组缺失时拒绝匹配连接，不静默直连。
- 预置更新不改写已应用的域名快照；重新保存并确认应用后才生效。
- 保留旧中转设置和接入备份，按所有权恢复旧接入，不覆盖其他程序更改。旧具体 URL 路径不静默扩大成域名，新路由需显式启用。

## 功能收敛与交互稳定性

- 程序代理暂时隐藏并关闭，后台扫描和原生命令同时停用，已有条目保留。
- 增强 OpenAI 稳定灾备及其界面、后台评分/探测/自动选点暂停。普通 AI 代理、自选节点、最低双节点和基础 Fallback 保留。
- 性价比倍率预算直接约束有效候选，合格节点少于两个时拒绝托管路径新请求；旧手动节点仅在合格候选内作为 Fallback 优先项，不承诺锁定失效节点。
- 修正选中系统代理、TUN 及共用按钮的悬浮文字颜色；同步主题状态。
- 订阅卡片支持右键、更多菜单和键盘编辑名称、地址、客户端标识，保留 ID、选用状态和历史版本；保存不隐式下载。并发编辑/旧下载结果有版本检查。
- 节点详情使用独立交互会话，重复点击合并；关闭、切页、切配置或切运行状态后，过期读取和重测结果不再打开弹窗。

## 验证与发布边界

- 使用真实前端 + 合成 IPC 做 Browser 界面测试；未操作用户运行中的 Serylane、系统代理、TUN 或 Codex 配置。
- 六平台构建、签名更新附件、下载中心和官网以自动化结果及集中验收记录为准，源码版本不代表安装包已发布。
- macOS 本轮仍为项目更新签名兼容包，Developer ID、Apple 公证和 TUN 不在已完成范围；未放宽身份检查。
- Gitee 当前因平台对仓库内容的公开限制，匿名源码和附件尚未恢复；保留完整性门禁，下载中心和 GitHub 为可用渠道。
