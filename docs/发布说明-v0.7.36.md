# Serylane v0.7.36

## 主代理启停一致

普通关闭系统代理或 TUN 使用与「停止」相同的操作：记录关闭意图、取消后台恢复，恢复本应用拥有的系统代理设置并停止核心。不会因关闭开关而转成仍在运行的 Manual 本地端口。停止成功后主状态显示「已关闭」，可再次点击「启动」。

停止保留上次网络模式与选用配置，下次启动按该模式执行原有检查；关闭后重启仍保持关闭。显式选择 Manual 的高级使用方式保留，旧 Manual 设置不会被静默改写。状态读取或清理失败会显示未完成／待核对，不提前显示完全关闭。

托盘停止完成后通过原生结果通知触发主代理和路由状态重新读取，减少只等待周期刷新造成的显示延迟；停止失败仍显示未完成并可重试。实际关闭状态由读回结果确认。

## 路由策略与当前可用状态

域名路由的启用意图、已应用名单和出口独立保存。主代理关闭时，已启用的路由显示「已启用 · 暂停，等待代理启动」；重新启动后，核对规则与系统代理/TUN 入口，再显示对应的就绪状态。只核对规则通过不能证明系统流量已经接管，Manual 只表示本地代理入口。

单独保存、开启或关闭路由不会启动核心、切换系统代理/TUN 或改变主代理恢复意图。出口缺失、非规则模式、规则不一致和读取失败分别显示原因；缺失出口仍拒绝匹配流量，不自动改用其他节点。启停、模式或订阅变化时，旧核验失效，完成后重新读回。

路由配置开关表示是否启用该策略，实际状态另行说明就绪、暂停或待核对；顶部和页内入口使用一致的结果，编辑草稿继续保留。系统全局流量是网卡收发统计，主代理关闭后仍可能显示流量。

## 发行与验证边界

安装包是否可用以[下载中心](https://downloads.cmmuu.com/projects/serylane)的实时发行结果为准；应用与官网仅使用下载中心，失败提示重试。实现与验证记录见[主代理与路由状态统一](主代理与路由状态统一-实施说明-2026-11-02.md)，源码版本不代表尚未完成的发行、归档或部署已经上线。

Windows TUN 仍为管理员会话下的实验性功能；macOS 兼容包的 Developer ID／公证限制和 Linux TUN 禁用边界不变。本轮不新增 Codex 接入或恢复已停用能力。隔离界面与状态回归不替代真实主机启停、开机恢复、IPv6、VPN 共存、休眠或模型长流验收。
