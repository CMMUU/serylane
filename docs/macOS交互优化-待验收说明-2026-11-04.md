# macOS 交互优化：候选实施与原生菜单待验收

2026-11-04 后续按用户确认方案二，已替换为独立 AppKit NSStatusItem/NSStatusBarButton/NSMenu 所有权，不再隐藏 TaoTrayTarget 或合成点击。以下原始“隐藏依赖视图”的描述保留为上一候选快照，不是当前实现。

- 左右键交给原生按钮和菜单；本地点击观察只返回原事件，无全局事件 tap。菜单开合、动作排队与窗口就绪分别记录，业务动作延后到菜单关闭。
- 主线程管理所有原生对象及观察令牌，卸载时取消菜单跟踪、清除委托与非持有目标、移除状态项；已排队动作在卸载后失效。
- 图标/双行流量复用既有绘制与位图降级、S 品牌和紧凑宽度；显示开关与采样共用合并队列，菜单期间延后变更，关闭采样后仍会提交被延后的最新关闭状态。
- 普通桌面/Dock 形态保留，窗口恢复不改系统 Space 设置或强制置顶。诊断有界观察可见、最小化、焦点、活动 Space；关闭可取消旧观察，不循环抢焦点。
- 原生所有权、延后动作/卸载失效、图标绘制测试通过；真实内置屏全屏左右键与主窗口输入仍是独立门禁。
- 隔离夹具首次真实启动暴露原 data URL 缺少 feature 的错误。此后 about:blank 的 WebKit 初始文档也未形成可验证内容，已改成真实 Tauri 窗口上的独立 AppKit 标签/输入控件，不增加 feature 包或加载生产页面。该夹具验证原生菜单、窗口/焦点，不冒充 WebKit 前端验收；--self-test 核对窗口、菜单和原生控件，并以 --self-test-force-failure 验证失败返回码，两者接入 macOS 两架构 CI。

本轮不替换真实应用、不修改代理/Tailscale/系统偏好；不把候选能力写成已发版。

## 已实现的候选改动

- 当前节点先展示可关闭的加载态，关闭/切页后的迟到响应仍丢弃；固定详情弹窗高度、保留关闭按钮，防止响应返回时按钮移位或替换造成丢点击。
- 页面按钮在等待读取队列之前反馈。读取总并发 4，后台读取最多占 2 槽；同资源合并、前台提升、队列上限和超时保护保留。已运行的原生读取超时后不释放假空位；写操作不自动重试。
- 基础刷新按相互一致的核心状态、订阅状态分组提交，版本探测及补充状态独立返回；代次与变更保护保留。
- 订阅任务状态查询明确归入只读，避免轮询反复使其他读取失效。
- 节点详情必要控制接口有 4 秒预算，Provider 补充信息独立并行、300 ms 预算；缺失时明确展示未返回，不把空字段误报为已知信息。
- 主题与设置持久化移出原生事件线程，仍使用配置事务、生命周期入口检查和实际完成结果。
- macOS 左键改为菜单；候选适配隐藏锁定 tray-icon 0.24 的事件覆盖视图，保留 AppKit 状态按钮与原生菜单。依赖契约不匹配时保留原视图并记录提示。此机制仍需实际菜单栏点击验收。
- 窗口恢复保留当前页面，不强制导航概览；补 Dock Reopen；750 ms 后核对可见、非最小化、聚焦和活动 Space，结果记入本地日志。
- 流量采样与托盘绘制解耦，最多一个待执行绘制，读取最新样本；菜单跟踪期间暂缓绘制，减少重复图片/字体/宽度更新。

## 尚未通过的验收门禁

当前 CUA 只返回测试窗口区域和应用菜单，未暴露系统菜单栏状态项；读取 SystemUIServer 超时。因此没有完成“内置屏幕上的其他应用全屏 → 实际点击测试托盘 → 菜单出现 → 显示主窗口并可交互”的完整验收。应用菜单成功或绘制测试通过均不替代这一项。

候选原生入口：`src-tauri/examples/macos-interaction-fixture.rs`。仅按人工验收需要运行；没有生产 setup、插件、代理命令或用户配置读取。分别运行默认入口和 `--companion`；通过伴随窗口原生绿色按钮全屏，检查测试状态项的左/右键、显示、隐藏、最小化、连续点击，结束退出两个夹具。不会替换已安装 Serylane。夹具默认状态项保留明确的 QA 标识；`--traffic` 为单独的动态标题压力入口，验收时通过“显示测试窗口/退出测试”菜单确认所属进程。
