# macOS 交互优化：待验收说明

本轮基于远程 main `40e2d425752093597805e6580a1ee763e356f987`（v0.7.37）实施已确认的方案二。**本分支是候选源码，不是正式发行；全屏菜单关键实测未通过验收门禁，暂不合并或发版。**

完整分析和本轮进度维护于 [project-docs 项目入口](https://github.com/CMMUU/project-docs/tree/main/serylane)。

## 已实现的候选改动

- 当前节点先展示可关闭的加载态，关闭/切页后的迟到响应仍丢弃；固定详情弹窗高度、保留关闭按钮，防止响应返回时按钮移位或替换造成丢点击。
- 页面按钮在等待读取队列之前反馈。读取总并发 4，后台读取最多占 2 槽；同资源合并、前台提升、队列上限和超时保护保留。已运行的原生读取超时后不释放假空位；写操作不自动重试。
- 基础刷新按相互一致的核心状态、订阅状态分组提交，版本探测及补充状态独立返回；代次与变更保护保留。
- 订阅任务状态查询明确归入只读，避免轮询反复使其他读取失效。
- 节点详情必要控制接口有 4 秒预算，Provider 补充信息独立并行、300 ms 预算；缺失时明确展示未返回，不把空字段误报为已知信息。
- 主题与设置持久化移出原生事件线程，仍使用配置事务、生命周期入口检查和实际完成结果。
- macOS 左键改为菜单；候选适配隐藏锁定 tray-icon 0.24 的事件覆盖视图，保留 AppKit 状态按钮与原生菜单。依赖契约不匹配时保留原视图并记录提示。此机制仍需实际菜单栏点击验收。
- 窗口恢复保留当前页面，不强制导航概览；补 Dock Reopen；750 ms 后核对可见、非最小化、聚焦和活动 Space，结果记入本地日志。
- 流量采样与托盘绘制解耦，最多一个待执行绘制，读取最新样本；菜单跟踪期间暂缓绘制，减少重复图片/字体/宽度更新。

## 已执行验证

- Node：357 项通过。
- macOS Rust：433 项通过，5 项显式忽略；另通过原生双行流量图标/正常字体/位图降级/浅色深色/1×2× 绘制测试。
- TypeScript/Vite build、Rust clippy `--all-targets -D warnings`、格式化、品牌、许可证和产品事实校验通过。
- 官网现有测试通过（14 项 Worker/部署单测及静态、下载校验）。本轮未部署官网。
- Browser plugin not available；使用已安装的 Playwright + 本地 Vite 隔离 IPC 页面，拒绝非 loopback 请求。三套平台界面配置各 100 次快速导航、同资源单次在途、鼠标按下到抬起之间刷新、离页迟到响应、10 秒慢读下导航全部通过。
- 1320×768、1024×768 验证详情立即显示、加载中关闭不重开、数据到达期间关闭按钮不变且不移位、慢 5 秒版本探测不阻塞基础刷新。截图只含合成节点。
- 两个独立原生测试进程已启动；对照窗口进入/退出全屏、原生应用菜单可操作，测试结束后两进程均退出。实际 Serylane/Mihomo 未重启。

## 尚未通过的验收门禁

当前 CUA 只返回测试窗口区域和应用菜单，未暴露系统菜单栏状态项；读取 SystemUIServer 超时。因此没有完成“内置屏幕上的其他应用全屏 → 实际点击测试托盘 → 菜单出现 → 显示主窗口并可交互”的完整验收。应用菜单成功或绘制测试通过均不替代这一项。

候选原生入口：`src-tauri/examples/macos-interaction-fixture.rs`。仅按人工验收需要运行；没有生产 setup、插件、代理命令或用户配置读取。分别运行默认入口和 `--companion`；通过伴随窗口原生绿色按钮全屏，检查测试状态项的左/右键、显示、隐藏、最小化、连续点击，结束退出两个夹具。不会替换已安装 Serylane。

后续顺序：补齐上述验收 → 审阅/跨平台 CI → 升版并发布 → 下载中心校验 → 官网对应说明部署与公开验证。本轮不修改 Tailscale 出口、DNS、网卡绑定、用户代理或 TUN 能力。
