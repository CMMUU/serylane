# Serylane v0.7.32

## 菜单与按钮响应

- 快速切换菜单立即展示目标页面；重复点击当前菜单不再重复发起加载。轮询、导航和手动刷新共享在途读取，切页或配置变化后旧结果不覆盖当前页面。
- 刷新按钮显示执行状态；慢请求不锁住其他导航，失败保留当前列表并支持重试。窗口不可见时暂停非必要的界面轮询，不停止代理或后台任务。
- 连接、订阅、节点和概览卡片采用稳定控件更新，减少刷新期间点击丢失；保留焦点与展开状态，连接关闭操作防止重复提交。
- 节点、连接与生效规则长列表按 200 项分段显示，支持继续加载；搜索仍覆盖完整数据，不截断实际配置或节点测试范围。

## 原生状态读取

- macOS 系统代理查询、连接反馈和配置摘要读取移出 UI 主线程；后台读取并发有界，系统命令超时后终止并回收子进程。
- 查询失败不伪造“系统代理已关闭”；界面保留最近已知状态并提供重试。代理变更前的实时所有权检查仍保留，不使用展示缓存代替校验。
- 配置摘要采用有容量限制的内容缓存，源文件变化时重新解析；Helper 状态读取独立刷新，不再阻塞整个基础页面加载。

## 支持范围

- Windows、macOS、Linux 共用读取调度及列表交互修复；不同平台的系统代理适配边界保持。
- 不改变订阅下载路径、AI 节点资格、路由目标或 Codex 配置，不调整 TUN 能力。macOS 继续使用既有兼容发行范围，Developer ID、公证和 TUN 状态不因本版本改变。
- 仍使用下载中心固定入口、同版本同架构备用源及完整性校验。实际可下载版本以正式发行和下载中心核验为准。
