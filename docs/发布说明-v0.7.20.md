# Serylane v0.7.20

[文档索引](index.md) · [集中项目文档](https://github.com/CMMUU/project-docs/tree/main/serylane)

本轮完善订阅添加与更新的稳定性和操作说明，不包含 TUN 修复或 Codex 路由接入。安装包与渠道交付状态以正式发行记录为准。

## 订阅下载与重试

- 新增「订阅下载路径」：默认跟随 Serylane，核心运行时使用其代理端口，未运行时明确直连；也可手动选择直连，或输入已运行的本地 HTTP 代理端口。
- 路径选择只影响本页手动添加与更新，不持久修改系统代理或后台用量检查策略，不自动启动核心，也不扫描其他代理软件。选择代理后失败不静默改成直连。
- 重试覆盖完整响应：HTTP 200 正文中途断开时丢弃半份内容，再完整获取，避免把不完整数据送入校验。
- 对 429、502、503、504 等临时错误有限退避，识别 Retry-After 秒数或日期。超出本轮等待预算时结束并给出稍后重试说明。
- 兼容请求头尝试、发送与正文重试共享次数和时间预算，最多额外一次瞬时错误重试；继续保留 30 秒获取预算、8 秒连接超时、HTTPS 校验、重定向限制与 4 MiB 内容上限。
- HTML 页面、非 YAML、空响应、超大内容与网络失败分别说明；不把真实订阅地址交给外部转换服务。

## 阶段进度与取消

- 添加和手动更新具有独立任务编号，展示连接、下载、内容检查、配置等待、Mihomo 校验和保存阶段，显示实际路径与请求次数。
- 下载、等待配置及原生校验阶段支持取消。取消后保留添加草稿和原有配置；校验子进程退出并清理临时文件后才释放配置锁。
- 已进入保存或核心配置事务时不再接受取消，避免半提交；界面明确等待完成。
- 进度查询失败或迟到回调不改变导入结果；成功后的列表刷新失败仍提示刷新列表，而非要求重新添加。

## 配置一致性与诊断

- 下载不持有配置修改锁；短暂配置操作冲突最多等待 8 秒，并可取消。
- 获得许可后重新读取订阅、设置和版本。并发更新改变了基础版本时拒绝旧结果覆盖；保留去重、现有配置事务和失败恢复。
- 新增固定结构诊断摘要：任务编号、添加/更新/额度检查、阶段、路径类别、耗时、HTTP 状态及尝试次数；不记录订阅 URL、参数、原始响应或节点凭据。
- 地理规则资源缺失或下载失败与订阅下载失败分别提示。原生配置校验仍保留，不通过略过校验宣布添加成功。
- 紧凑订阅卡片、自选节点与 AI 代理互斥、删除最后一个订阅的既有行为保持。

## 平台与签名范围

本轮沿用 v0.7.19 的明确兼容发行范围。macOS 包仍不包含 Developer ID 签名与 Apple 公证，**macOS TUN 未标为已修复**；保留辅助服务身份检查。Windows/Linux 保持原有平台边界。更新公钥、应用标识、数据目录与下载中心固定入口不变。

## 验收边界

本轮以本地可控 HTTP 故障服务、隔离配置目录和合成界面覆盖正文断流、限流、格式错误、配置等待、取消清理、提交边界、重复添加及成功后刷新失败。未访问真实订阅、替换本机运行应用或修改实际代理；真实订阅站和长时间网络稳定性需独立验收。具体测试结果、六平台流水线及下载渠道核验见集中项目文档。
