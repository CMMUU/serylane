# 应用绑定与自动跟随更新

[返回文档索引](index.md) · [v0.7.16 发布说明](发布说明-v0.7.16.md) · [集中方案与验收](https://github.com/CMMUU/project-docs/tree/main/serylane)

## 选择应用，而不是记住版本目录

「程序代理」支持从已安装应用清单搜索选择，也保留手动文件入口。先选择应用、设置代理方式并保存，再明确点击「代理启动」。保存、扫描和刷新不启动应用，不切换系统代理或 TUN；自动跟随已安装更新，不负责下载或安装更新。

| 平台 | 快选与身份 | 代理启动和工作目录 |
| --- | --- | --- |
| Windows | 当前用户 MSIX / Store 应用，保存包系列标识和 Application ID；普通及便携 `.exe` 保留手选 | 支持的桌面入口通过子进程启动；工作目录可跟随入口、自定义绝对目录或包内相对目录 |
| macOS | `/Applications`、`~/Applications` 等受限目录的 `.app`，或手选完整应用包；保存 Bundle ID、原选位置及可用签名要求 | NSWorkspace 原生启动新实例，传入代理环境和参数；GUI 应用使用系统原生工作目录，不静默忽略旧自定义目录 |
| Linux | 当前用户 XDG 应用目录的 `.desktop`，或手选 `.desktop` / 可执行文件 / AppImage；保存 Desktop File ID 和来源位置 | 普通桌面入口按规范拆解 Exec 为独立参数，使用 Path 或用户指定工作目录；不交给 shell 执行 |

macOS 不选择 `.app/Contents` 内部辅助程序，不凭最高版本替换用户选定副本。具有稳定签名要求的应用移位后仅在身份匹配且候选唯一时跟随；未签名或 ad-hoc 签名只按原位置跟随，移动后需重新关联。已有实例请先自行退出，再代理启动，新环境不会改写运行中的实例。

Linux 遵循 XDG 优先级、Hidden 覆盖、NoDisplay 和桌面环境过滤。注册来源发生变化时要求重新关联；XDG 外手选 `.desktop` 仅关联原文件位置。D-Bus 激活、Terminal、Flatpak/Snap 及环境/脚本包装入口显示「启动方式待适配」，不伪装成已代理启动。Windows 开始菜单 `.lnk` 全量索引与上述特殊入口的专用启动适配不属于本版本。

## 更快打开，后台更新

清单使用进程内缓存：打开即可搜索已有结果，过期时在后台刷新；30 秒内普通打开复用结果，「重新扫描」明确强刷。相同时间仅执行一次扫描。首次扫描显示进度，扫描失败保留已有清单并说明状态。

后台扫描不锁整个编辑表单，不清空搜索、焦点或未保存草稿；离开页面停止轮询，过期响应不回写。缓存仅用于展示，启动前仍重新核对真实身份、入口、参数和工作目录。

Windows 启动解析不等待显示名称查询；原生工作线程有界等待，安装事件使原生缓存失效。macOS 列表读取轻量元信息，实际启动前验证签名和应用身份。名称与当前版本主要展示，完整路径和标识收进详情；未安装、需要重新关联、读取失败、入口未就绪和待适配各有对应下一步说明。

## 参数、迁移与降级

代理方式、逐项参数和用户名称独立于身份保存。macOS GUI 旧自定义目录保持原值，必须明确选择「使用默认工作目录」后再保存；不会悄悄删除。Windows 包内相对目录仅适用于 Windows 绑定，跨平台条目原数据保留，需重新关联本机应用后启动。

首次写入 v3 前，原始 v1/v2 字节分别保留到 `proxy-programs.v1.backup.json` / `proxy-programs.v2.backup.json`，已有备份不覆盖。Windows 旧路径只在与当前注册入口唯一、精确匹配时自动绑定；确定属于包内的工作目录转相对路径，其余保持不变。失效旧版本不靠目录名猜身份。

v3 含 macOS/Linux 身份，旧版应用不认识新清单。降级前停止编辑并自行从对应备份恢复；不要用新清单覆盖原始备份。

## 启动与验证边界

子进程／原生新实例只收到本次代理变量，Chromium 模式另加受管代理参数。不更改全局环境，不强制关闭已有应用。启动结果未确定时显示「启动结果待确认」，禁止盲目重发；原生回执到达后刷新可核对结果。启动成功、软件遵循代理和实际网络可达是不同状态。

- Rust：三平台身份序列化、v1/v2 备份、路径与参数边界、缓存单飞及故障保留。
- Windows：原生 WinRT 查询和一次性托管 runner 的签名 MSIX v1→v2 安装升级；原有隔离安装验收保持执行。
- macOS：临时 `.app` 的 plist 更新、身份替换、签名检查、多副本、NSWorkspace 原生启动、中文参数、代理环境、实例退出和父环境不变；只运行合成应用。
- Linux：临时 XDG 目录、覆盖关系、本地化、字段代码、Exec 独立 argv、特殊启动方式及文件权限；Linux x64/ARM64 原生构建执行测试。
- 前端：三平台合成 fixture 的选择、编辑、后台刷新、失败保留、页面切换取消及 Mac 旧工作目录确认。

真实第三方应用的登录、升级、长会话、macOS 13 物理机和各 Linux 桌面／沙箱网络需要单独验收；本轮测试不操作用户正在运行的应用或代理。
