# Serylane v0.7.22

[文档索引](index.md) · [集中项目文档](https://github.com/CMMUU/project-docs/tree/main/serylane)

本轮统一桌面客户端、官网与下载中心的下载来源名称，仅调整文案和回归测试。

## 桌面更新文案

- 更新渠道显示“自动（下载中心优先）”“下载中心”“Gitee”“GitHub”。
- 自动回退说明、检查结果、当前渠道、新版本下载提示与后端渠道错误统一使用“下载中心”，不再以部署地区命名来源。
- 自动模式仍选择最高稳定版，同版本优先下载中心，再按既有规则回退 Gitee、GitHub；仅同版本、同摘要、同签名的包可跨渠道回退。
- 保留持久化的 `hk` 渠道标识，已有更新偏好无需重设；下载域名、清单地址、原文件名、更新公钥与签名校验均不变。
- 不修改真实节点的地区名称、订阅数据、代理方式或其他功能文案。

## 平台与验收范围

- Windows、macOS、Linux 共用本轮文案；验证前后端来源名称与旧渠道设置的读写兼容。
- 官网使用固定下载入口，实际安装包版本以正式发行记录为准；桌面文案随新版安装包生效。
- macOS 继续采用既有兼容发行范围，本轮不包含 Developer ID 签名、Apple 公证或 TUN 恢复。
- 不自动替换本机已安装应用，不启动、停止或调整用户的代理及 TUN。六平台发布、下载中心和官网验收结果在集中项目文档归档。
