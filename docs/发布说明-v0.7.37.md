# Serylane v0.7.37

诊断页面改为按实际检查过程逐条展示：当前项显示「检测中」，检查结束立即显示结果，再进入下一项。已有结果留在列表，顶部说明当前步骤与已完成数量，结束后汇总通过、注意、未通过和跳过项。

本地代理端口、控制接口端口和实际代理请求分别执行，不再等待所有网络检查结束后统一返回。单项失败保留具体原因并继续后续检查；核心未运行或运行状态读取失败时，网络项明确跳过，不伪装成成功。

重复点击不启动重复任务；重新诊断替换上一轮结果。离开页面、代理/配置变化及会话结束后，不采用迟到结果。检查仅观察当前状态，不启动代理、切换系统代理/TUN、选择出口或改变路由策略。

加载图标支持减少动态效果，结果按稳定标识更新，错误正文按文本展示。实现与验证边界见[逐项诊断](逐项诊断-实施说明-2026-11-02.md)。

安装包与应用内更新只使用[下载中心](https://downloads.cmmuu.com/projects/serylane)，实际可用版本以中心已核验的发行结果为准。Windows TUN 管理员会话实验性、macOS 兼容包签名限制及 Linux TUN 禁用边界不变。诊断请求通过不代表真实模型会话或长连接已验证。
