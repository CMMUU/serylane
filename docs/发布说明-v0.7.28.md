# Serylane v0.7.28

## 修复安装并更新

- 修正 v0.7.26/v0.7.27 将系统名称与系统＋架构直接比较的问题。正常已验签包不再在安装预检被误判；保留版本、平台、安装格式、官方地址、签名、大小和 SHA-256 校验。
- 更新检查、安装预检和测试共用候选身份及安装协调逻辑。预检未通过时代理保持运行；环境问题可保留包重试，身份或内容异常按具体原因处理。
- 补齐原生更新事务验收：签名下载、实际预检、替换、失败回退、重启失败保留证据与新进程版本确认。六平台发布门禁分别检查 macOS 应用包、Windows NSIS/MSI、Linux AppImage，不把安装器启动成功等同于完成升级。
- 增加只读 `--serylane-update-probe`，供隔离安装验收确认新进程的版本和平台；该入口不初始化窗口、用户配置、登录项或代理。

## 现有旧版首次迁移

v0.7.24–v0.7.27 的旧更新器在替换前仍运行旧代码。首次请从[下载中心](https://downloads.cmmuu.com/projects/serylane)核对 v0.7.28 或更高修复版的实际附件，下载对应平台和架构的完整安装包；退出旧应用后覆盖原位置，保留独立配置目录。之后使用修复版内置更新。重新下载现有 v0.7.27 不会修正其更新器。

## 支持范围

- 不修改订阅、节点选择、域名路由或 Codex 配置。
- Linux deb/rpm 继续使用原包管理方式更新，内置替换面向 AppImage。
- macOS 仍沿用兼容包发行范围，项目更新签名与 Apple Developer ID/公证分开；本版不宣称恢复 macOS TUN。
- Gitee 受平台公开限制时单独报告；下载中心与 GitHub 保留同版本同架构来源，不降低镜像完整性检查。
- 自动化使用隔离安装位置与合成数据；用户本机的原位覆盖、真实 GUI 会话及 OS 登录/重启验收单独记录。
