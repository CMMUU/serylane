# Serylane v0.7.44

- 在「设置 → 界面语言」选择 11 种语言。语言名称以母语显示，切换后当前窗口即时重绘并自动保存，保留页面与草稿。阿拉伯语使用从右到左的布局。
- 软件更新依次检查 GitHub 直连、通过运行中的 Serylane 代理访问 GitHub、下载中心。启动后在后台检查，发现新版时右下角显示卡片，点击直达「设置 → 软件更新」。
- 下载恢复只接受同一版本、平台和架构的工件。大小、SHA-256 和项目更新签名全部通过后，由用户确认安装。官网完整安装包由[下载中心](https://downloads.cmmuu.com/projects/serylane)提供。

macOS 沿用带项目更新签名的兼容包。该发行方式不含 Developer ID 签名或 Apple 公证，macOS TUN 仍受原有签名条件限制。
