# Serylane v0.7.41

- **AI 手动选点**：点击「应用节点」后，只有 Mihomo 确认所选节点已手动固定且是实际出口，按钮才会变灰并显示「已应用」。选择其他节点可再次应用；自动模式下的当前节点也可以手动固定。切换只影响命中该组的后续新连接，不主动断开已有连接。
- **macOS 菜单栏**：左键或右键点击图标，打开原生快捷面板，不切走当前应用。面板显示全局流量；再次点击图标、点击面板外或按 Esc 可收起。可明确选择打开主窗口（保留当前页面）、停止代理或退出。Windows/Linux 托盘操作不变。

本版沿用 macOS 兼容包，不改变 TUN、Tailscale 或签名策略。其他应用全屏时的物理点击由安装后实测，与自动 AppKit 检查分开记录。

应用内更新与完整安装包均来自[下载中心](https://downloads.cmmuu.com/projects/serylane)。以中心实时校验的可用版本为准。
