# Serylane v0.7.19 候选版

[文档索引](index.md) · [集中项目文档](https://github.com/CMMUU/project-docs/tree/main/serylane)

当前为候选源码及待重新构建的安装包，尚未公开发行；下载中心和官网的最新正式安装包仍以实际 Release 为准。候选包签名、Apple 公证与真实 TUN 接管分别验收，构建通过不作为 TUN 成功的结论。

## macOS TUN 与发行身份

- 使用 Developer ID 官网分发路线，沿用原应用标识、配置目录、辅助服务标识及更新公钥；不改为 App Store 版本。
- 稳定版发布前必须具备 Apple 签名与公证配置；临时签名只用于不公开发布的 CI 构建，部分凭据或签名失败不降级。
- 主程序、TUN 辅助服务、登录辅助程序和 Mihomo 分别验证 Developer ID、同一团队及 Hardened Runtime；正式发行仍额外验证公证票据和 Gatekeeper。
- 旧版本服务登记继续使用已有「重新关联辅助服务」入口：停止代理后注销旧登记、登记新服务并核对真实版本握手，不以文件存在或已登记代替已就绪。

## 提示与检测结果

- 安装检查失败改为「此安装包暂未满足 TUN 要求」，提供「查看诊断」，不再一概要求重复下载或打开设置授权。
- TUN 预检或恢复失败时不再拼接之前系统代理的成功检测；预检失败仍保留原网络模式。
- Windows 与 Linux 的现有支持边界不变。

## 订阅与配置

- 卡片保留名称、状态、剩余流量、到期和刷新／选用；上传下载、采样与版本等低频信息移入详情。异常、用尽、过期保持可见。
- 添加、更新与后台用量查询在 Serylane 核心已运行时复用其本地代理端口；未运行时沿用普通请求路径，不为下载自动启动核心，不扫描其他应用。已选本地代理失败时不静默改为直连；本地订阅地址直接请求以避免代理循环。
- 瞬时传输失败最多追加一次重试，共享 30 秒总预算；连接超时 8 秒。保留 HTTPS 校验、重定向限制、4 MiB 上限和原生配置校验。
- 提示区分服务拒绝、限流、超时、DNS、安全连接和内容错误；失败保留草稿与旧配置。某次接口成功不代表所有网络环境稳定。
- 「配置」中的订阅记录从同一订阅结果同步名称、版本与删除状态；本地 YAML 独立分组保留。

## 自选节点：与代理策略二选一

- 新页面从已添加订阅中搜索并固定一个独立节点；显式确认后重新加载，未运行的核心只保存供下次启动使用。
- 自选模式的实际有效配置只有所选出口，订阅策略组、自动灾备和用户分流规则暂不参与。代理页与概览相关操作同步禁用，后端也校验互斥；在途自动任务不得覆盖手动选择。
- 切回代理模式恢复当前订阅原策略和用户规则；原订阅与历史版本不改写，切换失败恢复旧设置和配置。
- 节点消失或连接信息变化时提示重新确认，不自动换到其他出口；相同连接字段的 YAML 排序变化不影响身份。开启系统代理、TUN 和选节点保持独立。
- 当前自选列表支持订阅 YAML 中保存的独立节点；动态 proxy-provider 与带 dialer-proxy 的链式节点继续在代理页使用，并显示说明。选点不主动断开已有连接，既有长连接另行验证。

## 验收状态

本轮 macOS 本地静态检查、315 项 Rust 单元测试、233 项前端测试及隔离界面验收通过；真实订阅沿已运行代理路径完成 3 次下载和原生校验，约 1.33／1.36／3.88 秒。前序签名候选包不包含本轮改动，需要重新构建。多平台 CI、候选包和实机测试详细进度记录在集中项目文档。正式发布前仍需确认 Apple 公证、本机旧服务重新关联、TUN 启停与实际流量接管。登录、重启、休眠恢复和其他硬件另行实测。
