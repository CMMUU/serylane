# Serylane v0.7.19 候选版

[文档索引](index.md) · [集中项目文档](https://github.com/CMMUU/project-docs/tree/main/serylane)

当前为本机候选构建，尚未公开发行；下载中心和官网的最新正式安装包仍以实际 Release 为准。候选包签名、Apple 公证与真实 TUN 接管分别验收，构建通过不作为 TUN 成功的结论。

## macOS TUN 与发行身份

- 使用 Developer ID 官网分发路线，沿用原应用标识、配置目录、辅助服务标识及更新公钥；不改为 App Store 版本。
- 稳定版发布前必须具备 Apple 签名与公证配置；临时签名只用于不公开发布的 CI 构建，部分凭据或签名失败不降级。
- 主程序、TUN 辅助服务、登录辅助程序和 Mihomo 分别验证 Developer ID、同一团队及 Hardened Runtime；正式发行仍额外验证公证票据和 Gatekeeper。
- 旧版本服务登记继续使用已有「重新关联辅助服务」入口：停止代理后注销旧登记、登记新服务并核对真实版本握手，不以文件存在或已登记代替已就绪。

## 提示与检测结果

- 安装检查失败改为「此安装包暂未满足 TUN 要求」，提供「查看诊断」，不再一概要求重复下载或打开设置授权。
- TUN 预检或恢复失败时不再拼接之前系统代理的成功检测；预检失败仍保留原网络模式。
- Windows 与 Linux 的现有支持边界不变。

## 验收状态

候选包、静态检查、自动化回归和实机测试的详细进度记录在集中项目文档。正式发布前仍需确认 Apple 公证、本机旧服务重新关联、TUN 启停与实际流量接管。登录、重启、休眠恢复和其他硬件另行实测。
