# Serylane v0.7.19

[文档索引](index.md) · [集中项目文档](https://github.com/CMMUU/project-docs/tree/main/serylane)

本轮按已确认范围先发布订阅、配置同步与自选节点功能。macOS 使用与上一版一致的兼容包：具备项目更新签名与代码完整性校验，未包含 Developer ID 签名或 Apple 公证，**macOS TUN 本轮仍未就绪**。下载中心和官网只在安装包完成发布与校验后切换到新版本。

## macOS 兼容发布范围

- 本轮明确启用兼容发布，不导出或上传 Apple 私钥；后续 Developer ID 官网分发与公证单独推进，不改为 App Store 版本。
- 发布流程默认仍要求 Apple 签名与公证；仅受信任 main 的显式手动发行允许选择兼容包。已配置部分 Apple 凭据或正式签名失败均不自动降级。
- 所有平台仍验证更新签名、SHA-256 和完整安装包集合；应用标识、配置目录、辅助服务标识及更新公钥不变。
- 保留 macOS TUN 的 Developer ID、同团队身份检查；不通过放宽辅助服务信任条件来启用 TUN。重复授权、重新关联或下载本次兼容包均不会补齐 Developer ID 身份。

## 提示与检测结果

- 安装检查失败改为「此安装包暂未满足 TUN 要求」，提供「查看诊断」，不再一概要求重复下载或打开设置授权。
- TUN 预检或恢复失败时不再拼接之前系统代理的成功检测；预检失败仍保留原网络模式。
- Windows 与 Linux 的现有支持边界不变。

## 订阅与配置

- 卡片保留名称、状态、已用／总量与剩余、到期／更新和刷新／选用；上传下载、采样与版本等低频信息移入详情。异常、用尽、过期保持可见。
- 添加、更新与后台用量查询在 Serylane 核心已运行时复用其本地代理端口；未运行时沿用普通请求路径，不为下载自动启动核心，不扫描其他应用。已选本地代理失败时不静默改为直连；本地订阅地址直接请求以避免代理循环。
- 瞬时传输失败最多追加一次重试，共享 30 秒总预算；连接超时 8 秒。保留 HTTPS 校验、重定向限制、4 MiB 上限和原生配置校验。
- 提示区分服务拒绝、限流、超时、DNS、安全连接和内容错误；失败保留草稿与旧配置。某次接口成功不代表所有网络环境稳定。
- 「配置」中的订阅记录从同一订阅结果同步名称、版本与删除状态；本地 YAML 独立分组保留。

## 自选节点与 AI 代理二选一

- 新增「自选节点」菜单，按当前订阅／本地 YAML 的原策略组选节点，支持搜索、名称／延迟排序、逐节点测速、规则／全局／直连模式；动态提供器和链式代理继续由 Mihomo 按配置处理，不再强制收缩为单一 MATCH 出口。
- 「代理」页明确命名为「AI 代理」。两种选点方式在有效配置、后端操作、后台筛选与灾备切换上互斥，不只是隐藏控件；切换需确认，失败回滚设置和运行配置。自选模式保留原订阅及用户分流规则。
- 新安装默认自选节点；旧设置保留原 AI 策略意图。历史预览版固定出口需明确确认迁移，不静默改写出口含义。没有配置时显示未启用，选点偏好仍保留。
- 切换保留双方偏好；模式版本号拒绝迟到请求，即使切换后又返回同一模式，旧任务也不得回写。节点选择只影响后续新连接，不主动关闭已有连接。
- **Codex 路由接入不包含在互斥范围内**：不改它的启停、接入状态、设置或账号；仍保持独立确认与默认关闭的既有边界。网络接管方式（系统代理／TUN）也不会因切换选点方式自动开启。
- AI 分流按规则模式参与；既有全局／直连偏好不静默改为规则。若需要 AI 专用分流，先在自选节点中选择规则模式，再确认使用 AI 代理。

## 删除当前及最后一个订阅

- 不再要求至少保留一个订阅，也不要求先激活其他配置。删除当前配置需确认停止代理和恢复由本应用接管的系统代理设置，不自动改选其他订阅，不生成隐式直连配置。
- 删除非当前订阅不打断当前配置及待恢复任务；本地 YAML 独立保留，外部原始文件不删除。配置与订阅列表同步更新。
- 后端配置操作串行化，清理活动配置／版本、运行配置与启动意图。磁盘阶段保留恢复记录，进程中断后在会话恢复前完成清理；用量回调与删除协调，迟到任务不重建已删除条目。
- 系统代理已被其他设置改动时，保留配置并提示先核对，不使用旧快照覆盖其他应用。
- 零配置时保留添加订阅／导入 YAML 入口，启动按钮停用；重新添加后需明确选用，不自动启动网络接管。

## 验收状态

本机已通过 317 项 Rust 单元测试、235 项前端测试、142 项发布脚本测试；规则／全局／直连配置通过隔离 Mihomo 原生校验。真实前端配合合成数据已验证选点、搜索、模式互斥、删除当前／最后一条、零配置状态和 1280／900 px 窗口；正常订阅卡片实测高度 170 px，异常信息自然增高。

历史订阅下载修复曾沿已运行代理路径完成隔离验证。本轮未再次访问真实订阅，未替换本机安装包或变更本机网络设置。正式交付以六平台流水线、GitHub／HK／Gitee 附件和官网在线核验结果为准；Apple 公证、macOS TUN 启停与实际流量接管、登录／重启／休眠及真实长会话另行验收。
