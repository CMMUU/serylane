# Serylane v0.7.46

- 在其他应用全屏时，从 macOS 菜单栏点击 S 图标可在当前空间打开非激活 AppKit 快捷面板。若 WebKit 在首次页面加载前退出，从菜单打开主窗口时会重新加载应用界面。
- 启动时后台检查更新。确认有新正式版后，主窗口在右下角显示卡片，侧栏版本号显示红点。关闭卡片后仍可点版本号进入「设置 → 软件更新」，定位下载或安装操作。
- 应用内依次使用 GitHub 直连、GitHub 加速代理、经 Serylane 本地代理访问 GitHub、下载中心。切换下载路径时核对同一工件的版本、平台、架构、大小、SHA-256 和签名。

macOS 安装包使用 Developer ID 签名和 Apple 公证。官网安装包由[下载中心](https://downloads.cmmuu.com/projects/serylane)提供。
