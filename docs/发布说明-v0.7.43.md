# Serylane v0.7.43

- **macOS 原生菜单**：改用系统标准 AppKit 菜单，背景、圆角、键盘导航和收起跟随系统样式。在其他应用全屏时可从菜单栏图标左键或右键打开。
- **操作与状态统一**：菜单保留实际代理状态、全局流量，以及系统代理、TUN、路由确认、刷新、启动和停止。和主窗口共用控制器，不重复提交，旧菜单选择不会反向修改新状态。
- **收起行为**：选择命令后菜单收起，后台操作继续。点击菜单外或按 Esc 可关闭菜单；选择「打开主窗口」回到原页面。

本版 macOS 为兼容发行，保留更新签名和 SHA-256 检验，不包含 Developer ID 签名或 Apple 公证，不宣称 macOS TUN 已可用。Windows、Linux 的代理入口和能力边界不变。

应用内更新与完整安装包均由[下载中心](https://downloads.cmmuu.com/projects/serylane)提供，以中心实时校验的可用版本为准。
