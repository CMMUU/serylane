# Serylane v0.7.33

## Windows 退出与状态探测

- 修正未启用代理时，状态/路由刷新反复执行 Mihomo 版本探测的问题；停止和退出只读取快照，不再为查询版本启动核心。
- 显式版本探测按文件身份缓存、并发去重；文件变化后重新检查，失败允许稍后重试。
- 统一核心启动、配置校验、版本探测的进程准入；Windows 准备结束会话时暂停新任务，取消后恢复，确认退出后不重新开放。
- 安装更新使用独立暂停原因，失败释放安装暂停，但不会覆盖正在进行的系统关机。
- Windows 退出清理的等待预算为 4 秒；保留 Job Object 子进程回收、代理所有权及恢复日志，不把退出改成用户主动停止。
- 状态读取和前端轮询识别生命周期变化，旧会话结果不覆盖新状态；正常关闭到托盘不触发退出暂停。

## 平台与验收边界

- Windows x64/ARM64 验证原生窗口会话消息、取消与确认结束、不同用途的进程创建门禁；测试只向隔离测试窗口发送消息，不广播或执行系统关机。
- macOS/Linux 共用纯状态快照与版本缓存；保留各自资源清理语义。macOS 临时签名包仍不具备 Developer ID、公证和可用 TUN 身份；本轮不宣称修复 macOS TUN。
- 保留现有下载渠道、签名和摘要校验、路由规则、订阅配置与用户运行意图。
- 真实 Windows 关机、注销、快速启动及原始弹窗复测单列，不把自动化用例等同于用户电脑已完成关机验收。

本文件描述本版本改动。发行附件与渠道可用性以正式发布和下载中心核验结果为准。
