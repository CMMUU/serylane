# Serylane v0.7.50

- macOS 启动时等待菜单栏状态项落位，再显示 S 图标。
- 双行流量按落位后的按钮外框重绘，避免首帧上行被裁切。
- 保留 AppKit 原生菜单。仅图标和双行状态项均支持全屏下左右键展开，菜单中的「打开主窗口」会显示原进程的窗口。

## 验收

正式 v0.7.49 和候选在 Apple 芯片 macOS 27.2.1 隔离环境分别完成普通桌面与其他应用全屏的两种布局测试，共 80 次有效启动。候选从首个可见帧到稳态的 S 图标纵向最大偏差为 0.036 pt。实体屏报告的明显下落保留为独立验收项。

TextEdit 保持全屏前台时，左右键均打开原生菜单。选择「打开主窗口」后，核对到原 Serylane 进程的窗口。该隔离环境中正式 v0.7.49 和候选的 WebView 均出现内容空白，页面视觉验收待单独复核。 [实施与验收记录](https://github.com/CMMUU/project-docs/pull/19)
