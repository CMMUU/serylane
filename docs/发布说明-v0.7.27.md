## 路由双入口与紧凑配置页

- 顶部「系统代理／TUN 模式」旁增加独立「路由」开关；路由页同时保留「开启／关闭路由」和「刷新状态」。不是三选一：系统代理与 TUN 互斥，域名路由可叠加使用。
- 两个入口共用后台状态、确认和执行锁；开启/关闭中禁用重复提交，失败不提前显示成功。从其他页面也能启停，未配置有效域名和出口时给出操作提示。
- AI 工具紧凑展示，范围按需展开；自定义地址与出口并排，窄窗口自动换行；重复说明收入折叠区，浅色/深色/深紫沿用应用主题。
- 保存草稿不改变当前流量；路由已开启时可「应用更改」，不需要先关闭再开启。未保存编辑不被自动应用，仍可立即发起关闭。
- 刷新保留编辑和展开状态，丢弃过期读取结果；核心停止、非规则模式和出口缺失仍展示真实原因，不把「已配置」等同于流量已生效。

## 发布边界

- 本轮不改变后台域名匹配、订阅策略、Codex 配置、系统代理或 TUN 实现；不恢复程序代理或增强稳定灾备。
- 六个平台使用同一版本源；macOS 兼容包仍不代表 Developer ID、公证和 TUN 已就绪。保留上一版内置更新校验和回退机制。
- Gitee 当前受平台公开限制，下载中心和 GitHub 为公开下载来源；Gitee 同步状态单独记录，不以构建成功代替同步完成。
