# 启动提速与友好提示

[返回文档索引](index.md) · [启动模式与状态恢复](启动模式与状态恢复.md) · [v0.7.11 发布说明](发布说明-v0.7.11.md)

## 行为约定

v0.7.11 将本地代理开启和外网健康检查分开。系统代理启动仍执行配置校验、端口检查、核心控制 API 就绪、系统设置备份及读回验证；外网检测在本地接管完成后运行，不再等待 Google、Cloudflare、OpenAI 的慢响应才返回成功。

- “系统代理已开启”只表示本地接管已完成。
- “正在检查网络连接”及检查失败独立显示。部分目标失败不停止已开启的系统代理，也不重放模型请求。
- OpenAI 401 仅表示接口可达，不表示真实模型会话已验收。
- Manual 与 System Proxy 使用相同的非 TUN 核心配置；在已运行状态切换这两种模式时只修改系统登记和保存偏好，不主动重启核心。TUN 仍走完整的权限、启动与验收流程。
- 普通核心启动只校验一次实际使用的配置；特权 TUN 的准备校验保留。核心控制 API 就绪检查具有严格总截止时间。
- 系统代理操作结束不等待无关的 TUN Helper 界面探测。

## 事务与结果归属

系统代理变化和偏好保存作为事务协调；失败尝试恢复该操作之前的 OS 状态及所有权文件，分别报告恢复成功和恢复失败。后台检查不拥有任何代理设置写入权限。

后台任务绑定操作代次、配置 ID/版本、网络模式、端口和核心 PID/启动时间。新操作、停止、退出使旧任务失效；配置变化后的旧结果不更新当前健康状态。不同检测的错误不归因为单一节点故障。

## 提示规则

| 状态 | 主提示 | 用户下一步 |
|---|---|---|
| 配置校验 | 正在检查代理配置 | 等待 |
| 核心启动 | 正在启动代理服务 | 等待 |
| 系统登记 | 正在应用代理设置 | 等待 |
| 本地完成、外网待测 | 系统代理已开启；正在检查网络连接 | 可继续使用 |
| 基础检测成功、OpenAI 失败 | 基础连接正常，OpenAI 检查未通过 | 重新检查或查看详情 |
| 检测全失败 | 连接检查暂未通过，代理保持开启 | 重新检查或查看诊断 |
| 端口占用 | 代理端口正在被使用 | 打开设置 |
| 设置写入失败 | 系统代理设置未完成 | 查看恢复结果和设置 |

主要提示使用标题、影响和有效操作；原始错误码、目标和耗时进入可展开的技术详情。TLS 连接中断和证书校验失败分别描述；未知冲突不推断为某个其他软件占用。等待时间据真实操作计时，不显示虚构百分比。

## 验收与边界

自动化回归覆盖状态分类、迟到结果、配置归属、严格就绪截止时间以及系统代理启动路径不等待外网检测。浏览器使用真实前端和隔离 IPC，检查慢网络反馈、热切换调用序列、窄窗口及错误详情。

这些验证不等于物理机系统代理接管、真实登录/重启或长期 Codex 稳定性验收。发布不会替换本机正在运行的应用或改动其网络设置。

- Playwright：1280×920 和 920×820；Manual→System Proxy→Manual 只调用模式切换，不调用停止/重新启动。模拟的后台检查等待 3 秒期间，本地开启提示约 0.15 秒显示（这是 IPC 合成场景，不是物理机启动性能）。
- 冷启动合成场景约 0.31 秒显示本地已开启，网络仍在检查；检查期间停止后，迟到结果没有复活状态。端口占用提示的操作按钮正确进入设置。
- 官网新增说明和 FAQ 已在桌面及 390px 宽度检查；静态预览没有真实发布 API，下载解析以生产部署后的公开路由验证为准。
- 未操作当前运行的 Serylane、代理、Codex 接入或系统登录项；真实重启和当前用户线路的性能验证单独进行。
