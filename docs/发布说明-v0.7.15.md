## 地区与流量倍率

- 根据节点名称中的明确地区、国旗和常见城市筛选 OpenAI 托管节点，采用带版本和来源的 API 支持地区规则；未知、多地区冲突及部分地区受限的名称不进入候选。
- 候选生成、历史策略、自动容灾和专用组手动选点使用同一规则，普通代理组保持原行为。旧策略不足两个合格节点时保留托管规则并拒绝新请求，提示重新生成，不静默转回普通出口。
- 自动读取名称里的 `0.5x`、`×2`、`倍率:0.8` 等明确倍率，保留有效手动覆盖优先级；清空覆盖恢复自动识别。未知、冲突或非法倍率不默认成 1×。
- 节点和成本设置显示地区排除原因与倍率来源；质量优先、性价比、预算、健康节点保持及手动固定的既有意图不改变。

名称是地区及倍率的线索，不是实际出口 IP、账户可用性或真实账单的验证。

## 订阅剩余流量

- 应用运行期间每约 5 分钟直接读取订阅服务商用量，按总额度减上传与下载计算剩余流量；余额变化更新卡片，不使用本机流量估算套餐额度。
- 独立后台 worker 优先 HEAD，必要时通过 GET 获取响应元信息，不应用配置正文；不切换订阅、不新增配置版本、不重载代理核心。
- 请求失败或缺少用量头时保留上次采样，显示检查与采样状态；较旧的后台请求或整页读取不覆盖较新的用量观测。

## 升级与验收

保留用户配置、更新身份和运行意图。路由默认关闭，保存、启动服务和接入 Codex 仍是分开的操作。不主动关闭连接或重放模型请求。

v0.7.14 构建后因缺少随版本发布说明而停止发布，已有标签保持不变。本版本补齐说明，并将同项预检提前到 CI 和构建前，避免先创建标签再发现文档缺失；更新签名、六架构产物完整性和镜像校验保持执行。

GitHub/Gitee 安装包与官网六架构入口按实际发布验证结果提供。本轮自动化使用合成配置；物理机登录/重启、真实地区出口、服务商账单和长期网络会话需分别验收，不以构建或单元测试代替。
