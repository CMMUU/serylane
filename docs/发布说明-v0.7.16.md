## macOS / Linux 应用快选与代理启动

- macOS 可快速选择完整 `.app`，按 Bundle ID、原安装位置和可用签名身份关联；正常更新自动解析，多个副本不随意替换。
- 通过 NSWorkspace 原生启动新实例，传入代理环境和参数，按进程、启动时间、应用身份跟踪；已有实例提示自行退出，不强制结束。
- Linux 从 XDG `.desktop` 清单选择，遵循覆盖优先级并按规范解析参数、工作目录和可执行权限；继续支持手选普通可执行文件及 AppImage。
- D-Bus、Terminal、Flatpak/Snap 和包装启动器明确显示待适配，不将发现应用等同于已支持代理启动。
- Windows 原有 MSIX / Store 绑定和普通 `.exe` 选择保持；启动前原生解析不再等待应用显示名称。

## 缓存、后台刷新与友好说明

- 已安装清单打开即展示已有缓存，后台单次刷新；普通打开复用 30 秒缓存，「重新扫描」主动强刷。
- 刷新期间可继续编辑和搜索，保留焦点、草稿及原参数；失败保留上次结果，离开页面不再轮询或写入旧结果。
- 文案按平台和状态给出下一步：未安装、需要重新关联、读取失败、启动方式待适配、已有实例及启动结果待确认。
- macOS 自定义工作目录不静默忽略：保留旧设置，明确确认使用系统默认目录后再保存。

## 迁移与交付

程序清单升级到 v3，旧 v1/v2 原始字节分别备份，名称、参数、代理方式及可兼容目录保持。展示缓存不作为启动依据，启动前重新验证应用身份。

同步更新 README、程序说明、集中项目文档、官网功能介绍和 FAQ。六平台构建、Windows 隔离安装、原生测试、签名更新清单和 GitHub/Gitee 完整资产校验继续作为发布门槛。实际下载版本由官网动态核验，不把源码部署当成安装包发布。

程序代理不会切换系统代理／TUN或改全局环境；保存与启动是独立操作。验证使用临时合成应用，不代表真实第三方应用的登录、长期联网、macOS 13 物理机和所有 Linux 桌面已验收。
