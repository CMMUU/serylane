# Serylane v0.7.48

- macOS 菜单栏使用 AppKit 原生菜单。仅图标和双行流量状态项都支持左键与右键，菜单外观和收起行为由系统管理。
- macOS 从 TUN 切到系统代理时，若已退出的 TUN 内核还有连接正在清理，应用会在限定时间内等待配置端口可用。若端口有实际监听进程，则报告冲突。
- macOS 首次启动会检查 TUN 辅助服务的旧版登记。通过完整安装包覆盖升级时，也会恢复已确认属于 Serylane 且启动失败的旧登记。
- 如果 macOS 要求批准后台服务，在「系统设置 → 通用 → 登录项与扩展」批准 Serylane，返回应用后继续恢复。新辅助服务通过身份、版本和协议核对后显示就绪。
- 应用日志记录恢复阶段和系统错误，以便定位许可、旧服务移除、重新登记及握手失败。
