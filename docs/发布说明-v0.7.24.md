## 下载和安装

- 客户端下载显示当前来源、真实选择的网络路径与备用源尝试；同版本、同架构的摘要和更新签名检查保持不变。
- 官网和下载中心点击时重新解析已核验包，显示本次实际来源；永久入口保留。网页只确认交给浏览器，不声称文件已经保存完成。
- 安装条件预检前置，空间或目录问题在停止代理前说明；安装阶段与下一次启动确认独立记录。
- macOS 兼容同身份同位置的旧升级记录，保留服务意图。TUN 等可选服务尚待恢复，不再阻止后续软件升级；登录服务独立恢复。
- macOS 安装前备份旧应用，替换或签名完整性验证失败时回退旧应用；回退异常保留备份路径。Windows/Linux 沿用各自安装器，补充公共预检和状态提示。
- 如果旧版本安装器已经被历史服务记录阻断，首次请使用完整安装包替换原位置应用，保留配置；新代码不会在旧安装器运行前自动生效。

## 平台展示

- “系统代理兼容性”检查只在 Windows 展示和绑定事件；macOS/Linux 不显示这张卡，不移除系统代理功能。

## 本地路由 URL 名单

- 默认允许现有 `https://chatgpt.com/backend-api/codex` 和 `https://api.openai.com/v1`。支持增删、行首 `#` 暂停和恢复默认草稿。
- 清空表示不转发，不默默恢复默认。旧设置缺失名单才迁移到默认值。
- HTTPS origin 精确匹配、路径段边界匹配；拒绝账号密码、查询参数、片段、编码路径和重复规则；最多 100 条。
- 只限制已经进入本地路由的请求。其他域名规则不自动改上游或发送官方凭据；AI 代理、自选节点、订阅规则、系统代理和 Codex 接入配置不调整。
- 保持关闭默认值、保存与启动分离；运行中和关联未恢复时不热改名单。HTTP/SSE/WebSocket 原有协议边界和不重放模型请求的行为保持。

## 发布边界

- Gitee 恢复公开访问先核对原仓库身份，单独预演和批准执行；保留所有原有完整性与配额门禁。是否全渠道交付以集中验收记录为准。
- macOS Developer ID、Apple 公证与 TUN 验收不在本版完成范围；没有放松签名身份检查。不要把软件更新修复理解为 TUN 已就绪。
- 本地回归与隔离界面测试不等同于真实系统重启、登录或原位升级验收；不会自动安装到用户正在使用的应用。
