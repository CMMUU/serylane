# Serylane v0.7.18

候选版本：正式安装包以 GitHub Release、Gitee 附件验证和官网验证结果为准。

## 登录启动与升级

- macOS 改用原生服务管理登记登录启动，独立短生命周期启动器精确打开当前应用包。
- 分开显示“登录打开应用”与“打开后恢复代理”；核对实际系统状态，提供修复和系统设置入口。
- 精确迁移旧登录项，保留用户关闭与系统禁用选择，不因升级自动开启。

## TUN 辅助服务

- 注销旧服务后等待系统完成，再注册并验证真实 Helper 构建版本与签名身份；超时后不重复登记。
- 初始化中的短暂等待显示“正在等待系统辅助服务启动”，版本不匹配提示“需要与新版应用重新关联”。
- 更新安装前持久化服务关联事务，安装失败恢复旧关联，新版启动按原意图恢复；处理中和失败不显示已就绪。
- 异步 XPC 加入有界等待；会话恢复期间点击停止保留取消意图，不后台安装服务或改变代理模式。
- 区分安装包签名异常、辅助程序启动失败和等待系统批准：启动失败显示“需要重新关联”，签名异常提示更新完整安装包，不再长期停留在“正在等待”。
- 注册后的短暂连接拒绝在有界窗口内重试握手，不重复注册；修复前先校验完整安装包与签名团队，避免先卸掉旧服务才发现新版包有问题。
- 对 launchd 的只读诊断设定超时、大小和缓存边界；只有真实身份握手通过才报告就绪，历史退出码不覆盖当前运行状态。

## 香港下载中心

- 客户端新增香港来源，官网六个平台/架构入口接入香港下载中心。
- 更新下载回退必须匹配同版本、大小、SHA-256 与原始签名；macOS 区分 Intel 芯片与 Apple 芯片。
- 独立下载中心支持管理员上传、公开下载、草稿与发布；文件归档未就绪时继续使用已验证的同版本备用来源。
- GitHub、HK、Gitee 分开显示状态；HK 可用不等于 Gitee 已同步。

## 发布与验收

- macOS 增加实际安装包布局门禁，显式声明主程序与两个 Helper，避免附加二进制漏包。
- 正式 macOS 包要求 Developer ID、Hardened Runtime 与公证票据，缺发布凭据时停止发布。
- 六平台打包前一次性检查 Apple 发布凭据名称；只报告缺少哪些配置，不输出凭据内容。
- 自动测试、调试包布局检查与真实登录/升级/重启/TUN 网络验收分开记录。
