# Serylane v0.7.11

## 系统代理开启不再等待外网检查

- 本地核心和控制 API 就绪、系统代理写入并读回验证后，即完成开启；Google、Cloudflare、OpenAI 检查移至后台。
- 网络检测慢或部分目标失败时，代理保持开启，页面单独展示检测状态。OpenAI 可达不等于模型会话已验证。
- 已运行的 Manual / System Proxy 之间切换不再主动重启核心。TUN 模式继续执行完整权限与验收流程。
- 合并普通启动中的重复配置校验，控制 API 就绪遵守总截止时间，系统代理完成反馈不等待无关 Helper 状态读取。

## 看得懂的状态与提示

- 分别显示正在检查配置、启动服务、应用设置，以及开启后正在检查网络。
- 提供真实等待时间、持续的异常提示、重新检查及可展开的技术详情，避免多个成功/失败弹条互相覆盖。
- 端口占用、配置问题、系统设置失败和恢复结果给出对应说明；证书校验问题与连接中断分别展示。

## 状态保护与验证

- 后台检查绑定本次配置和核心，停止、退出或新操作后丢弃旧结果；检查不修改网络设置或重放请求。
- 系统登记和偏好保存失败时恢复操作前状态，并区分回滚是否完成。
- 保持应用/Helper 标识、数据目录、更新签名公钥、历史兼容附件和 Codex 路由默认关闭。
- 自动化及隔离前端测试与真实网络、登录/重启验收分别记录。本次发版不会替换用户当前运行的应用。

详见 [启动提速与友好提示](启动提速与友好提示.md)。
