# 启动模式与状态恢复

[[index|返回文档索引]]

## 交付状态

本说明对应 v0.7.8 的启动模式实现。正式安装包及发布可用性以对应 Release、签名和同步回验为准；发版不自动替换用户已安装的应用。真实登录、重启和网络环境验收单独记录，不重写历史安装包。

## 行为约定

启动模式控制用户登录后的应用启动方式，不启动登录前的系统级代理服务。

| 模式 | 登录项 | 主窗口 | 代理状态 |
|---|---|---|---|
| 不随系统启动 | 关闭 | 由用户手动打开 | 保留已有恢复偏好及启停记录 |
| 登录后后台恢复上次状态 | 开启 | 登录时隐藏，手动打开仍显示 | 恢复原模式、选用配置及启停状态 |
| 登录后打开窗口并恢复 | 开启 | 显示 | 恢复原模式、选用配置及启停状态 |
| 保留旧版自定义设置 | 不改写 | 沿用原设置 | 用户明确选择其他模式并保存后才替换 |

三项旧持久化字段继续使用：`launchAtLogin`、`silentStartup`、`restoreLastSession`。读取设置、查看状态及编辑未保存的模式，不登记登录项或启动代理。模式草稿不被异步刷新覆盖。

v0.7.10 修正旧设置缺少 `silentStartup` 时误按 `false` 处理的问题：新设置及缺失字段默认静默，已有明确 `false` 则保留“打开窗口”偏好。登录项仍须用户启用；不会因升级开启未登记或已被系统禁用的自启动。窗口创建时保持隐藏，重复 `--autostart` 不唤起主页，手动打开及托盘操作才显示窗口。旧设置无需先打开设置页保存一次才能使用默认静默。

## 启停意图

- 手动启动成功后保存 `desiredRunning=true`；启动失败不虚构成功记录。
- 明确停止时先保存 `false`，再清理本次代理接管。停止可中断待恢复或等待网络的任务。
- 关闭窗口只隐藏界面。托盘退出、系统退出及升级清理继续保留启停意图；退出不等同“停止代理”。
- 改变启动模式不改变当前代理状态，也不把已关闭的代理自动开启。
- 系统代理、TUN、本地端口模式沿用原设置；权限、配置或代理所有权冲突保持暂停，不自动提权、换模式、接入 Codex 或启动其他程序。

## 系统登录项核对

`get_startup_status` 区分保存的启动偏好、系统登记状态、显式禁用标记和记忆的代理状态。读取失败或平台缺乏有效证据时返回未知，不把配置勾选或文件存在解释为真实重启成功。

- macOS 使用现有 Tauri LaunchAgent，核对操作只读取登记及 launchd 禁用标记，不执行 load、enable 或 bootout。读取有时间和输出大小上限，其他应用的登记内容不持久化或打印。
- Windows 核对现有注册项与 StartupApproved 标记；未知状态不推断为已允许。
- 仅登录启动偏好发生改变时写系统登记，随后读回验证，再保存设置；失败时尝试恢复此前登记状态，并显示错误。
- 单独改变静默或恢复偏好不重新启用被系统禁用的登录项。新旧身份迁移沿用既有规则。

## 网络等待

初次启动延迟 1 秒。可重试的临时网络预检失败后按 5、15、30、60 秒退避，随后每次至少等待 60 秒，不因固定次数耗尽而丢失开启意图。每次尝试重新核对保存的状态和配置。

用户停止、手动操作、配置变更或退出会使旧任务失效；取消优先于下一次启动。等待期间“停止”按钮保持可用。证书、权限、配置及外部代理冲突不进入无限重试。

## 影响面

- 前端：设置模式入口、模式草稿、登录项反馈、恢复提示、等待期间的停止按钮。
- 后端：登录项只读检查、设置保存协调、已有恢复任务的退避和取消。
- 兼容：保留旧设置字段、启停状态文件、应用/Helper 身份和更新签名，不修改路由默认关闭的约定。

## 验收清单

1. 代理开启后重启并登录：无主窗口闪现，使用原模式和配置恢复。
2. 代理停止后重启并登录：应用可后台运行，代理保持停止。
3. 网络延迟超过初始重试窗口后可恢复；等待期间点击停止后不再次启动。
4. 登录项缺失、系统禁用、读取失败分别显示，不报告为恢复成功。
5. 修改启动模式不触发代理启停；保存失败保留模式草稿，核对状态不写系统设置。
6. 旧自定义偏好、手动打开、托盘退出以及 Windows 禁用状态保持兼容。
7. 浏览器合成预览只验证界面和模拟交互；实际登录、重启及跨平台安装须单独验收。
