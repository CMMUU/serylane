# Serylane v0.7.31

## AI 代理

- 最少 1 个合格节点即可生成和恢复策略，最多保留 10 个；单节点明确显示“暂无备用”，两个及以上支持基础故障切换。零合格节点继续保护托管路径，不改地区、预算与质量条件。
- 立即健康检查改为后台任务：点击即时反馈、单任务防连点、进度与取消、完成时间及逐节点结果。配置、模式或核心变化后隔离旧任务；检测不主动改选出口，自动组仍按核心原策略运行。
- HTTP 401 是接口预期探测响应，不代表账号登录或模型请求可用；控制接口认证错误、坏响应和零延迟不误报节点可达。

## 订阅

- 配置更新与用量查询独立记录，成功与失败互不覆盖；兼容旧状态记录，明确旧记录未区分操作类型。
- 下载保留有限重试和实际路径，改善连接等待与正文停滞恢复：15 秒连接、30 秒单请求、15 秒正文无进度、60 秒整个获取预算；原生校验独立有界。
- 区分 TLS 证书校验与握手中断，保留 HTTPS 校验。不完整响应丢弃并完整重试，不拼接旧正文；选定路径失败不静默改走直连。
- 页面保留最近任务结果，超时显示请求路径、次数和耗时；原配置与用量记录保留。

## 平台与更新

- macOS、Windows、Linux 共用以上逻辑；保留既有更新签名、同版本备用源和完整性门禁。
- 本轮不修改 TUN、路由目标或 Codex 配置。macOS 仍按兼容发行范围提供安装包，Developer ID / Apple 公证与 TUN 支持状态不因本轮变化。
- 默认下载继续使用下载中心固定入口；GitHub/Gitee/官网同步与真实网络验收分别记录，不将合成测试当作所有服务商均可用的证明。
