# Serylane v0.7.40

- **添加订阅**改用弹窗。点击空白处、按 Esc 或点关闭只收起窗口；再次点击「添加订阅」可继续填写当前会话的草稿。已提交的导入在后台继续，可以重新打开查看进度或取消。失败或取消保留草稿，保存成功后清空。
- **按钮反馈**：健康检查、应用节点和单项／批量测速会在原按钮上显示加载。后台刷新保留焦点及正在编辑的选择，重复点击不会重复提交同一操作。
- **AI 手动选点**：合格且倍率明确的节点，点一次「应用节点」即可提交。界面从 Mihomo 核对目标策略组，确认实际出口后才提示成功，不等待全量列表刷新。仅影响命中该组的新连接，不主动断开已有连接。允许使用的未知倍率节点仍需确认。

本次不调整 TUN 支持、Codex 接入、路由规则和节点准入。原生 macOS 桌面端到端点击时延尚未单独实测；隔离界面及真实 Mihomo 测量不等同于正式安装版实测。

应用内更新及安装包均使用[下载中心](https://downloads.cmmuu.com/projects/serylane)。可下载版本以中心实时核验结果为准。
