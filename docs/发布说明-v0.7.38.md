# Serylane v0.7.38

在「AI 代理 → OpenAI 自动灾备」重新筛选节点后，候选按推荐顺位显示编号，实际使用的出口单独标示。订阅列表也为有有效结果的订阅显示推荐顺位，订阅由用户选用。

筛选使用两轮轻量探测，检查 ChatGPT 的 robots.txt 是否返回 200 和 OpenAI 的 /v1/models 是否返回 401。评分权重为可归因的真实流完成率 45%、连接可达率 25%、流量倍率 20%、延迟与波动 10%。真实流样本不足时显示「待验证」，按已有探测和成本信息提供暂定推荐。普通系统代理下，网页探测的 200 和 API 的 401 都只说明各自目标的可达性。

自动模式在当前订阅内选择合格候选，健康的当前节点会继续使用。确认故障后，失败节点进入冷却，后续新连接改用排名靠前的可用节点。可继续手动选点或恢复自动。性价比模式按设置过滤倍率上限及未知倍率。旧筛选结果继续使用基础 Fallback，重新筛选后应用新排序策略。

安装包及应用内更新使用[下载中心](https://downloads.cmmuu.com/projects/serylane)，可用版本以中心核验结果为准。真实 Codex 长任务的完成率需要单独验证。
