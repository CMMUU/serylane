# Serylane v0.7.49

- macOS 的辅助服务准备好 TUN 后，可以在系统代理与 TUN 之间热切换。两种模式共用一个普通用户核心及原配置端口。
- 系统代理设置使用 macOS 原生接口批量应用。辅助服务负责 TUN 接口和路由，切换失败时恢复原模式。
- 单独启动 TUN 时，首个基础连通性探测通过即可继续，其余诊断在后台完成。
- 覆盖升级时，自动重新关联仍在运行且闲置的旧辅助服务。匹配原版本、签名和系统许可后，再登记新版服务。
- 在已授权的 Apple 芯片 macOS 27.2.1 隔离环境，三种操作各测 50 次。按操作开始到受控业务请求成功计时，系统代理切 TUN、TUN 切系统代理、单独启动 TUN 的 P95 分别约为 563、436 和 853 毫秒。样本包含 IPv4、IPv6 和 DNS。
