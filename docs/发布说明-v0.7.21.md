# Serylane v0.7.21

[文档索引](index.md) · [集中项目文档](https://github.com/CMMUU/project-docs/tree/main/serylane)

本轮优化 macOS 菜单栏图标与双行速率的左右留白，不修改网络、订阅、TUN 或 Codex 路由行为。实际下载与渠道状态以正式发行记录为准。

## 更紧凑的菜单栏

- 双行网速状态项从 78pt 收紧到 64pt，横向占位减少约 18%；保留 9.5pt 数字字号、原有双行高度和数值/单位列。
- 菜单栏 S 图形仍派生自应用同一份素材，只去掉多余的左右透明画布。可见图形不缩放、不拉伸，Dock 与安装包图标保持不变。
- 正常显示、字体位图备用和像素备用共用稳定的宽度预算；速率或单位变化不让相邻菜单栏图标来回移动。
- 备用路径使用与原生一致的 B/K/M/G/T/P/E 格式和单位进位，并按双行实际高度显示，而不是将整个图像缩到单图标高度。
- 保留系统亮暗着色、选中态、原生菜单与悬停提示；关闭流量显示后恢复纯图标，重新开启恢复紧凑双行。

## 验收与平台范围

- 原生测试使用生产图标，覆盖极值、单位进位、稳定列位置、亮暗/选中、1x/2x、两行边界、左右点击区域、菜单对象保持，以及原生与备用切换后的几何。
- 备用渲染检查固定尺寸、透明边缘、同源图形、支持单位与两行不相连；不以宽度常量检查代替实际渲染。
- Windows/Linux 保持现有托盘逻辑；没有新增布局设置或直接依赖。
- 本轮继续采用既有 macOS 兼容发行范围，不包含 Developer ID 签名、公证或 TUN 恢复。更新公钥、应用标识、配置目录和固定下载入口不变。

本机实际安装与正在运行的应用未替换，代理和 TUN 状态未调整。系统菜单栏胶囊与外部留白仍由 macOS 绘制，64pt 指应用状态项的逻辑占位。六平台发布与下载核验结果在集中项目文档归档。
