# Serylane v0.7.10

## 开机静默启动修复

- 修正旧版设置缺少 `silentStartup` 字段时被默认视为关闭，导致带 `--autostart` 的登录启动仍打开主页。
- 新设置与缺失该字段的旧设置默认在托盘后台启动；明确保存过“登录后打开窗口并恢复”的用户保留原选择。设置 → 启动模式可选择“登录后后台恢复上次状态”。
- 窗口从创建时保持隐藏；重复的登录启动不唤起已有窗口。主动打开应用或点击托盘仍可显示主页。不会自动开启原本未登记或被系统禁用的登录项。
- 恢复沿用上次启停状态、配置与代理方式：已停止则保持停止；权限不足或其他代理占用时暂停，临时网络故障按既有规则等待重试。旧版未记录运行意图时不猜测上次已开启。

## 手动选点与概览详情

- OpenAI 灾备支持明确选择候选节点并应用；稳定优先策略保存本订阅的手动意图，直到明确恢复自动。
- 不使用 OpenAI 灾备也可独立切换普通代理组。Fallback / URLTest 为手动优先，失效时核心仍可能回退，界面显示实际出口。
- 概览展示普通组和 OpenAI 组的当前节点、链路、协议、延迟、脱敏来源及已填写倍率。核心停止、直连或读取失败时不冒用旧节点信息。
- 选点不重启核心、不主动清空既有连接；规则模式并不存在唯一全局节点，已断流无法靠换节点无缝续接。

## OpenAI 性价比策略

- 在代理 → 成本与性价比中，按服务商规则填写显式节点的流量倍率；空白是未知，不从名称或套餐用量猜测。节点连接信息变化后需重新核实倍率。
- 性价比模式先筛质量，再比较倍率，可设置倍率上限。未知费用默认不参与，明确允许未知兜底后不能保证费用上限。
- 自动切换保持健康且符合预算的当前节点；没有符合预算的健康候选时拒绝后续新请求，不擅自选择超预算节点。手动固定仍优先，未知或超预算手动选择需要额外确认。
- 性价比模式跳过每节点大流量带宽测试，基础连通探测仍消耗少量流量。探测通过不代表模型流完整验证；实际计费以服务商为准。
- 成本保存不启动核心、不生成灾备、不重放请求。稳定优先的下一轮检查使用新策略，重新生成才更换候选池；基础 Fallback 需先开启稳定优先才能执行预算限制。

## 验证与发布边界

- 前端交互、Rust 单元测试、品牌与许可证、官网及发布同步脚本检查均为发布门禁。
- Windows x64 / ARM64 安装验收在 GitHub 临时机器执行，覆盖旧设置缺失字段、隐藏窗口、重复登录启动、主动打开、停止状态代理不变和升级卸载。
- 不在用户正在工作的电脑上重启系统、替换运行中的应用或切换代理。真实物理登录/重启和实际模型流稳定性需另行验收，不以合成预览替代。
- GitHub / Gitee 使用同一组签名产物与摘要，官网区分六个平台架构并在点击时核对最新版本。保留既有应用身份、签名与历史标签；Gitee 按已确认策略仅保留最近一个版本的发布附件。
