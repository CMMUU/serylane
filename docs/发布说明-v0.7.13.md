# Serylane v0.7.13

## 本地路由与稳定性

- 502 不再只有笼统连接失败：区分本地代理、DNS、TLS/证书、超时、重置、上游 HTTP 与流式错误，并在路由页和应用日志查看分类。
- 分开显示 ChatGPT 与 OpenAI API 的基础检测、HTTP 未验证、失败和过期状态；明确自动检测是否运行、选点依据与模型流证据，不能将一次 401 当作完整验证。
- 网络异常触发合并限频复查；稳定节点保持、故障冷却、手动优先和流量倍率预算继续生效。多出口同时失败先保持合预算当前出口复查，不反复切换或给全部节点扣分。
- 不主动清空连接、不重发模型请求、不跳过证书校验；已经断掉的数据流不能无缝接续。

## 升级与发布

保留前一源码版本的 Windows 应用身份绑定、更新后自动跟随、重新关联与目录策略。本版本补齐测试程序重定位所需的 Windows 清单；Windows 身份验收使用隔离 CI 上真正签名安装的 MSIX 升级，不将松散开发目录注册误当作商店包运行身份。另消除 macOS 并行测试的端口竞争；不跳过原生测试、签名和镜像校验。

路由默认关闭，保存、启动服务和接入 Codex 仍各自独立。保留旧配置、更新身份和数据目录。GitHub/Gitee 使用相同签名安装包，官网同步功能说明；六种平台架构的下载仍以公开正式版实时解析。

测试不操作用户当前应用、代理或会话。物理机登录/重启、真实 TUN 和长期模型流稳定性不以单元测试或合成截图代替验收。
