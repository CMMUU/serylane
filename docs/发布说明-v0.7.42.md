# Serylane v0.7.42

- **macOS 菜单栏**：改为纵向、分组的圆角原生菜单。保留全局流量，直接控制系统代理、TUN 和路由，也可刷新、按已保存模式启动或停止代理。
- **控制与主窗口一致**：菜单和主窗口共用一个控制器，操作进行中不会重复提交；根据实际状态确认代理接管。路由开关仍需确认，仅应用已保存设置，不替换未保存草稿。
- **收起与打开**：菜单内操作后保持打开，不定时收起。再次点图标、点击菜单外或按 Esc 收起；只有明确选择「打开主窗口」才打开应用，并保留原页面。

本版不修改 SSE／WebSocket、Codex 接入、Windows/Linux 托盘、Tailscale 或 TUN 支持范围。macOS 沿用兼容发行策略。

应用内更新与完整安装包均来自[下载中心](https://downloads.cmmuu.com/projects/serylane)。以中心实时校验的可用版本为准。
