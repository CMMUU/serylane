# Serylane 사용 가이드

설치부터 구독 추가, 프록시 모드 선택, AI 도메인 라우팅, 업데이트와 문제 해결까지 안내합니다.

## 다운로드 및 설치
<!-- anchor: install -->

[공식 웹사이트](https://serylane.cmmuu.com/ko/#download) 또는 [다운로드 센터](https://downloads.cmmuu.com/projects/serylane)에서 정식 버전을 받으세요. 노드, 구독 또는 AI 계정은 제공되지 않습니다.

- Windows: Intel 또는 AMD 64비트 PC는 x64, Windows on Arm은 ARM64를 선택하세요.
- macOS: M 시리즈는 Apple Silicon, Intel Mac은 Intel을 선택하세요. DMG를 열고 Serylane을 응용 프로그램에 넣으세요. macOS 13 이상이 필요합니다.
- Linux: 기기 아키텍처에 맞는 AppImage에 실행 권한을 부여한 뒤 실행하세요.

## 빠르게 시작하기
<!-- anchor: quick-start -->

1. 구독 화면에서 이름과 Mihomo 또는 Clash Meta의 구독 URL을 입력하고 검증한 뒤 추가합니다. 로컬 YAML은 프로필 화면에서 검증하고 활성화합니다.
2. 사용하려는 프로필이나 구독이 선택되었는지 확인합니다. 프로필을 선택해도 프록시가 자동으로 시작되지는 않습니다.
3. 상단에서 시스템 프록시를 켠 후 평소 사용하던 사이트를 열고 연결 화면에서 요청이 코어에 도착했는지 확인합니다.

## 프록시 모드 선택
<!-- anchor: proxy-modes -->

- **시스템 프록시**는 운영체제의 프록시 설정을 따르는 앱에 적합합니다. Linux의 시스템 설정은 GNOME gsettings를 사용합니다.
- **TUN**은 시스템 프록시를 따르지 않는 앱에 적합합니다. macOS에서는 서명 및 공증이 완료된 전체 설치 파일을 사용하고, 필요한 경우 로그인 항목 및 확장 프로그램에서 도우미를 허용하세요. Windows의 실험 기능에는 관리자 권한이 필요합니다. Linux의 TUN은 지원되지 않습니다.
- **로컬 포트**를 수동으로 설정할 때는 `127.0.0.1` 및 Serylane의 혼합 포트를 HTTP 또는 SOCKS5로 지정하세요. 제어 포트는 사용하지 마세요.

도우미 준비 완료와 실제 트래픽 처리는 서로 다른 상태입니다. 연결 화면에서 확인하세요.

## 구독 관리
<!-- anchor: subscriptions -->

개별 카드 또는 모든 구독의 새로 고침을 실행할 수 있습니다. 사용량과 설정은 별개로 갱신되며 실패하면 마지막 설정을 유지합니다. 카드의 더 보기 또는 오른쪽 클릭으로 편집한 뒤 주소를 바꿨으면 다시 갱신하세요. 실패한 경우 계정 페이지가 아닌 Mihomo용 주소인지, 어느 다운로드 경로에서 실패했는지 확인하세요.

## 수동 노드 선택과 AI 프록시
<!-- anchor: nodes -->

두 모드는 동시에 사용할 수 없습니다. 수동 선택은 구독의 정책 그룹에서 노드를 선택하고 지연 시간을 측정합니다. AI 프록시는 조건에 맞는 노드 1~10개를 사용하며 1개면 예비 노드가 없습니다. 수동 적용 후 적용 상태를 확인하거나 자동 선택으로 복귀하세요. 변경은 이후 연결에만 적용됩니다.

## AI 도구, 도메인 및 Codex
<!-- anchor: ai-tools -->

도메인 라우팅은 기본적으로 꺼져 있으며 규칙 모드에서 코어에 도착한 연결만 처리합니다. 도구와 도메인, 출구를 선택해 초안을 저장한 뒤 적용하세요. `example.com`은 루트 도메인, `*.example.com`은 하위 도메인에만 일치합니다. [도메인 라우팅](https://serylane.cmmuu.com/ko/docs/routing)을 참고하세요.

macOS와 Windows의 지원되는 Codex CLI에서는 `codex --enable respect_system_proxy`로 실행하면 해당 실행에 기존 시스템 프록시 설정을 사용합니다. PAC를 켜거나 장애 조치 기능을 추가하지 않습니다. [OpenAI의 설명](https://learn.chatgpt.com/docs/enterprise/managed-configuration#use-the-system-proxy-for-native-client-requests)을 참고하고 실제 요청 완료로 확인하세요.

## 업데이트 확인 및 설치
<!-- anchor: updates -->

설정 → 소프트웨어 업데이트에서 버전과 소스를 확인하세요. GitHub 직접 연결, GitHub 가속 경로, 실행 중인 Serylane 프록시 경유, 다운로드 센터 순으로 시도합니다. 동일한 버전과 아키텍처, 서명을 확인한 뒤 설치합니다. 이전 버전 업데이트에 실패하면 같은 아키텍처의 정식 설치 파일로 교체하고 설정을 유지하세요. [다운로드 검증](https://serylane.cmmuu.com/ko/docs/verification)을 참고하세요.

## 문제 해결
<!-- anchor: troubleshooting -->

- 앱 트래픽이 표시되지 않는 경우: 시스템 프록시 또는 TUN이 활성화되었는지 확인하세요. 로컬 포트만 실행 중이면 앱 설정이 별도로 필요합니다.
- macOS TUN 승인 대기: 로그인 항목의 권한을 확인하세요. 도우미를 다시 연결해야 하는 경우 프록시를 먼저 중지하세요.
- 포트가 사용 중인 경우: 기술 세부 정보를 확인하고 종료 직후라면 기존 연결이 해제될 때까지 기다리세요.
- AI 요청에서 HTTP 401: 접속 가능하다는 뜻이며 로그인이나 모델 요청이 검증된 것은 아닙니다.

제보에는 버전, OS와 아키텍처, 모드, 시간, 비밀을 제거한 오류 정보만 포함하세요.
