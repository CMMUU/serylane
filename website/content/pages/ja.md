# はじめにと対応プラットフォーム

お使いの OS とアーキテクチャに合った正式版を選び、自分の Mihomo 設定を使います。主な機能と制限を確認できます。

## はじめに {#start}

サブスクリプションを追加して選択するか、プロファイルで YAML を取り込みます。システムプロキシを有効にして実際の接続を確認します。[ユーザーガイド](site:guide)に手順があります。

## 現在の機能 {#current-capabilities}

サブスクリプション、ノード、接続、ログ、診断に対応します。AI プロキシと手動選択は排他的です。[ドメインルーティング](site:routing)は既定でオフ、アプリ別プロキシと新規 Codex 連携は無効です。

## TUN と OS ごとの制限 {#tun-compatibility}

macOS は Developer ID 署名・Apple 公証済みの完全版とヘルパーの許可が必要です。Windows は試験的で管理者権限が必要です。Linux は TUN 未対応で、システムプロキシには GNOME gsettings を使います。

## ダウンロードとアーキテクチャ {#download-center}

[公式ダウンロード](site:home#download)で OS と x64 または ARM64 を選びます。M シリーズの Mac は Apple シリコンを選びます。配布状況は[ダウンロードセンター](https://downloads.cmmuu.com/projects/serylane)を参照してください。

## 過去のリリース {#history}

以前の記録は[英語の履歴](/docs/#history)と[簡体字中国語の履歴](/zh/docs/#history)で確認できます。記録は現在ダウンロードできるバージョンを示すものではありません。

# ドメインに応じて出口を選ぶ

コアに入った対象ドメインの通信だけを指定のポリシーグループに送ります。ドメインルーティングは既定でオフです。

## ツールとカスタムドメイン {#node-metadata}

OpenAI、Claude、Gemini のプリセットと独自のドメインを利用できます。`example.com` はルート、`*.example.com` はサブドメインのみです。プリセットを外しても独自の設定は残ります。

## 保存してから適用 {#save-apply}

現在のサブスクリプションから出口を選択して下書きを保存し、有効化または適用を確定します。一致しない通信は元のルールを使います。出口がなくなった場合は再選択し、直接接続には切り替えません。

## 共通のスイッチ {#global-controls}

上部のボタンとルーティング画面は同じオン・オフ状態を使います。状態を更新できますが、コアの起動やシステムプロキシ・TUN の切り替えは行いません。

## 実際の有効状態 {#enablement}

ルールモード、読み込まれたルール、通信の入口を確認します。保存済みだけでは有効とは限りません。新規接続のルールと出口を確認してください。

## プロキシ停止時 {#proxy-routing-state}

コアが止まると有効なポリシーは一時停止し、構成は保持されます。明示的にプロキシを起動すると再確認します。

## ノードと安定性 {#stability}

AI プロキシは条件を満たす 1〜10 ノードに対応し、手動選択とは併用できません。1 ノードに予備はなく、切り替えは新規接続だけに影響します。

## 制限 {#validation-boundaries}

TLS の復号、暗号化されたパスの判定、Codex 設定の変更は行いません。新規 Codex 連携、アプリ別プロキシ、旧安定化戦略は無効です。[AI ツールの使い方](site:guide#ai-tools)。

# ダウンロードと更新の検証

正式な配布元、アーキテクチャ、SHA-256、プロジェクト署名を確認します。OS 署名やヘルパーの許可は別です。

## 入手先 {#download-origin}

[公式サイト](site:home#download)または[ダウンロードセンター](https://downloads.cmmuu.com/projects/serylane)で同じ OS とアーキテクチャの正式版を選びます。GitHub ソースへのリンクは代替ダウンロードではありません。

## SHA-256 を照合 {#checksums}

同じリリースの `SHA256SUMS.txt` とファイル名・ハッシュを照合します。異なる場合はインストールしないでください。コマンド中のファイル名を実際の名前に置き換えます。

- Windows：`Get-FileHash -LiteralPath ./installer.exe -Algorithm SHA256`
- macOS：`shasum -a 256 ./installer.dmg`
- Linux：`sha256sum ./installer.AppImage`

## 更新署名 {#update-signatures}

更新機能はプロジェクト署名を検証します。手動で確認する場合は、その正式版の署名、マニフェスト、公開鍵を使います。

## OS の署名 {#system-signing}

プロジェクト署名は Windows Authenticode、Apple Developer ID、Apple の公証の代わりではありません。リリース情報で確認します。

## macOS TUN の確認 {#macos-tun}

署名・公証済みの完全版を使います。古いヘルパーで `EX_CONFIG` が発生した場合は、旧登録の解除と新ヘルパーの確認が必要です。求められたらログイン項目で許可し、アプリに戻って通信を確認します。

## ダウンロードの中断 {#update-downloads}

更新は GitHub 直接、加速経路、稼働中の Serylane プロキシ、ダウンロードセンターの順で試します。経路が変わってもバージョン、アーキテクチャ、サイズ、ハッシュ、署名を維持します。

## インストール失敗 {#update-installation}

エラーの段階を確認し、空き容量や権限を確認します。旧版の更新が繰り返し失敗する場合は、構成を保持して同じ場所に対応する完全版をインストールします。

## 過去の検証記録 {#verification-history}

古いリリースの詳細は[英語の記録](/docs/verification#verification-history)または[簡体字中国語の記録](/zh/docs/verification#verification-history)を参照してください。

# プライバシーとデータの扱い

ウェブサイト、ダウンロードセンター、デスクトップアプリは別のシステムです。閲覧によってプロキシや Codex 連携は起動しません。

## ウェブサイト {#website-data}

製品情報と公開リリース情報を表示します。アカウント、アクセス解析、広告トラッカーはなく、サブスクリプションや設定のアップロードを求めません。ローカルのプロキシにも接続しません。

## ブラウザーへの保存 {#theme-preference}

保存するのは外観の `serylane-theme` だけです。言語は URL で選び、Cookie や言語設定は保存しません。外観の選択をサーバーへ送信しません。

## ホスティング {#hosting}

配信と保護のため、ホスティングは IP、時間、パス、ブラウザーなど基本的なアクセス情報を処理します。

## ダウンロードと外部サイト {#downloads}

公開メタデータと対応パッケージのみを確認し、訪問者の Cookie や認証ヘッダーは転送しません。ダウンロード先や外部サイトはそれぞれの規定で処理します。[検証方法](site:verification)。

## デスクトップクライアント {#desktop-client}

設定、サブスクリプション、ドメインルールの処理はアプリの機能です。ドメインルーティングは既定でオフで TLS を復号しません。URL に含まれる認証情報は共有前に取り除いてください。

## 問題の報告 {#reporting}

[GitHub の問題報告](https://github.com/CMMUU/serylane/issues)を利用し、パスワード、トークン、購読 URL、元の設定は投稿しないでください。脆弱性の詳細は非公開の連絡方法があるか先に確認します。
