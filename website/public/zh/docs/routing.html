Serylane / 文档 / 域名路由

按域名分流，不替你切换网络接管。

路由使用代理核心内的域名规则，默认关闭。常见 AI 工具与自定义地址统一处理；保存草稿和确认应用分开，不新增 Codex 接入。安装包以下载中心核验结果为准。

官网界面是只读示意，不代表实时连接，不操作本机应用、代理或配置。程序代理与旧增强稳定策略当前也关闭；旧版说明不代表这些能力已启用。

常见工具与自定义地址

可勾选 OpenAI（ChatGPT / API）、Claude、Gemini（含 AI Studio / API）。默认草稿只选择 OpenAI。后台展开工具域名，和自定义条目统一校验、去重，界面可查看每个工具的具体范围。取消工具不会删除自定义条目。工具清单随版本更新，已应用名单保留原快照；重新保存并确认应用后才更新规则。

自定义支持 openai.com、*.openai.com，也可输入 https://*.openai.com/*。通配符只匹配子域，根域须另列。按域名处理全部 HTTPS/WSS 路径，不按加密 URL 路径拆分，不解密 TLS。共享登录、支付、客服、Google 公共资源以及语音 IP 不自动整域纳入；可按需补充明确域名。

保存与应用分开

  1. 勾选工具、补充自定义地址，并明确选择当前订阅的出口策略组。
  2. 点击「保存草稿」，当前流量规则保持不变。
  3. 关闭状态点击任一「路由／开启路由」按钮并确认；已开启时点击「应用更改」确认新草稿。路由规则优先于本地规则、AI 规则和订阅规则；未匹配流量保留原规则。

只处理已经进入代理核心的连接，规则模式下生效。核心停止、全局或直连模式会显示未生效原因。切换订阅后目标组缺失时，匹配流量拒绝连接而不是静默直连；请重选出口或关闭域名路由。关闭只撤下此模块的覆盖规则，不删除其他规则。

全局开关与简洁配置页

v0.7.27 起，顶部「系统代理／TUN 模式」旁增加独立「路由」按钮，路由页也保留「开启／关闭路由」与「刷新状态」。两处共用路由配置开关和当前状态；系统代理与 TUN 互斥，域名路由可与其中任一种配合，不切换网络接管方式。工具选择紧凑展示，域名范围和使用说明按需展开。

开启引导与真实生效状态

v0.7.29 增加配置引导与核心规则核对：尚未选择出口或编辑未保存时，顶部和页内入口引导到对应操作，不直接禁用；编辑改回原值可继续开启。不会自动替你选择出口。实际可下载版本以下载中心已公开安装包为准。

应用后核对核心的运行模式、规则总数及前置域名规则。v0.7.36 起进一步区分规则已加载与流量入口：只有当前系统代理／TUN 入口确认，才显示对应路由就绪；Manual 明确标注仅本地代理入口。等待核心、出口失效、规则不一致和状态读取失败分别说明；核对异常时可刷新或重新应用。失败保留编辑，回退也会核验结果，不把提交成功等同于生效。

代理停止，路由配置仍保留

路由开关表示是否启用这套策略，状态文字说明当前是否可用。普通关闭系统代理或 TUN 使用统一停止操作，保留上次网络模式；已经启用的路由进入暂停，下次启动后重新核验。关闭后重启仍保持主代理停止，不会因路由已配置而自动开启代理。

  • 两种接管都关闭、路由未启用：主代理和路由都显示已关闭。
  • 两种接管都关闭、路由已启用：主代理显示已关闭，路由显示「已启用 · 暂停，等待代理启动」。
  • 系统代理或 TUN 开启、路由未启用：主代理显示对应运行模式，路由显示已关闭。
  • 代理开启、规则及入口核验通过：路由显示已就绪，并说明系统代理或 TUN 入口。
  • 启停、切换或核验失败：显示正在核验或未生效原因，不沿用旧的成功标记。

单独保存、开启或关闭路由不启动核心，不切换主代理方式，也不改变其恢复意图。显式 Manual 仍可供应用手动连接本地代理端口；这不等于系统代理或 TUN 接管。全局网速是网卡流量统计，不是路由启用的证据。

OpenAI 节点推荐与自动选点

从「AI 代理 → OpenAI 自动灾备」重新筛选后，候选显示推荐顺位，实际出口单独标示。两轮轻量探测分别核对 ChatGPT 网页和 OpenAI API 的可达性。评分参考连接表现、倍率与延迟，真实流结果须有可归因的样本才能计分。普通系统代理下显示「待验证」。

当前节点健康时继续使用，确认故障后按排名改选后续新连接的出口。失败节点进入冷却，可继续手动选点。性价比模式按设置过滤倍率上限及未知倍率。单个合格节点即可使用，两个及以上才有备用。订阅列表的推荐顺位供手动选择，当前订阅的规则继续适用。

v0.7.39 在明确探测失败后，并行确认当前出口和备用线路。故障确认后为后续连接选用已核验的出口。30 秒是现场验收目标，实际成绩需通过隔离故障试验取得。

旧结果在重新筛选前沿用基础 Fallback。程序代理、旧增强稳定策略和新增 Codex 接入继续暂停。

旧接入恢复

旧的模型中转不再新增接入或自动重启。已有 Serylane 接入记录只按所有权恢复原配置；外部程序修改同一字段时保留备份并显示冲突，页面仅保留旧接入恢复入口。旧设置文件保留，不把旧启用状态或具体路径静默转成新域名路由。

验证边界

节点切换只影响后续连接，不重放模型请求，不承诺中断数据流无缝续接。HTTP 401 只能证明接口可达，不代表模型会话或账户可用。TUN 平台支持范围不因本轮调整改变。

Windows TUN 仍为管理员会话下的实验性功能；macOS 当前兼容包未满足 TUN 签名与公证要求；Linux 尚未实现 TUN 接管。查看平台支持边界。

工具范围来源

自有域名归组参考 OpenAI 网络说明、Claude 服务域名说明和 Gemini API 文档。预置范围是 Serylane 的域名分流选择，不是上述厂商对完整可用性的承诺。
