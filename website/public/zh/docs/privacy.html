清楚区分数据的去向。

官网、下载中心和你电脑上的代理客户端是不同系统。浏览官网不等于启动代理，也不会自动接入 Codex。

官网行为 本地主题偏好 托管访问请求 下载与外链 桌面客户端 安全反馈

这个官网做什么、不做什么

本站提供静态产品信息与文档，没有账号系统、分析统计或广告追踪，不要求提交订阅地址、认证令牌或本地配置。系统与架构选择、导航菜单以及常见问题展开只改变当前网页显示。

首页还会向本站接口查询公开发布信息；下载入口由服务器核对最新正式版、安装包元数据与文件可用性，再跳转下载，不要求提供个人代理配置。

我们的网页脚本不会连接你电脑上的代理端口、启动本地服务或桌面客户端，也不会修改系统设置。产品界面是非实时示意，不是实时连接检测。文档页不加载第三方字体、脚本或图片。

仅在本机保存主题偏好

官网只在浏览器本地存储中保存外观偏好，键名为 serylane-theme，允许值仅为 dark、light、system，分别表示深色、浅色和跟随系统。默认深色；跟随系统时读取浏览器提供的系统外观偏好。本地存储不可用或被禁时安全降级，不要求开放存储权限。

我们的脚本绝不会把这项已保存的主题偏好发送给服务器、下载中心或其他服务。它只用于本地网页显示，不是分析数据，也不是桌面代理设置。

官网脚本不保存语言、订阅、配置、凭据或用户档案，不设置追踪 Cookie。中英文通过英文路径、/zh/ 路径和对应页面链接切换，不保存语言值。桌面客户端自己的本地文件属于下方说明的独立边界。

基础访问请求仍会被处理

交付网页必然涉及请求。网站托管与内容分发服务会为页面交付和安全防护处理 IP 地址、请求时间、请求路径、浏览器信息等基础访问数据。选择语言路径也会让托管服务看到对应请求路径。

因此不能把本站描述为「完全不处理数据」。基础访问请求不同于收集代理配置、发送已保存主题偏好，或桌面客户端上传订阅与模型请求。下载服务还会分别处理它交付文件时产生的访问请求。

下载中心与外部链接

本站下载服务只向下载中心查询公开发布元数据，并检查下载中心文件域的对应安装包；不会转发浏览器的 Cookie、授权头或完整访问请求。仅选择核验通过的同版本、同架构包。

无法确认时提示失败和重试，不切换其他下载源、旧版本或其他架构。下载跳转后由下载中心文件域提供安装包，其访问数据按服务自身规则处理。

GitHub 链接仅用于源码、变更记录、许可证和问题反馈，不是产品安装包备用源。外部目标按自身规则处理访问请求；不要向陌生站点提交订阅和令牌。查看校验与签名说明。

桌面客户端与本地路由

订阅和代理配置由你自行提供。订阅地址可能包含访问凭据；分享截图、日志或问题报告前，请核对并删除令牌、完整订阅链接和个人信息。

在桌面客户端中，AI 工具与自定义地址保存在本机，后台统一编译域名规则。域名路由默认关闭，保存草稿与确认应用分开；不解密 TLS、不改写模型请求、不新增 Codex 接入。

旧接入仅按所有权检查恢复，保留外部程序修改和原备份。订阅编辑保留原记录，地址仅在主动打开编辑框时展示。程序代理与旧增强稳定策略仍停用。具体实现与当前版本边界见路由文档。

反馈问题，不公开秘密

可通过项目问题追踪反馈。公开问题页可被他人阅读，请不要粘贴密码、私钥、订阅凭据或未脱敏的配置。

需要报告安全问题时，先查看仓库是否提供合适的私密报告渠道，不要在公开页面披露敏感细节。
