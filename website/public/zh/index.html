03 / 开始之前

先把边界，
说清楚。

是否提供节点或订阅？

不提供。Serylane 是桌面客户端，不是代理服务。请自行准备订阅或本地 Mihomo 配置。

会自动开启路由或接入 Codex 吗？

不会。域名路由可选且默认关闭，选择工具和出口、保存草稿、确认应用分别进行。新增 Codex 接入和程序代理当前停用。 查看路由说明

TUN 支持所有平台吗？

Windows TUN 仍为实验性功能，需要管理员会话；macOS 兼容包的 TUN 尚未就绪，Linux 尚未实现。切换节点也不能续接已中断的数据流。 查看平台限制
