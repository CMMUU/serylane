路由能力，由你决定。

路由默认关闭。它为支持的 Codex 模型请求提供本地入口，不接管整个应用，不因保存设置而自动启动或接入。

官网中的路由界面是只读示意，不代表实时状态，也不会启动本机服务、修改代理或接入 Codex。下面的操作仅供你在桌面客户端中自行执行。

三个独立操作

  1. 保存设置。选择兼容模式（HTTP/SSE）或原生模式（WebSocket）、支持的官方入口和出站代理。留空出站代理表示使用客户端当前本地代理端口。保存只保留设置。
  2. 启用服务。单独确认后启动本机路由监听。此时还没有修改 Codex 的提供方配置。
  3. 确认接入。单独确认后，先备份用户级 config.toml，再写入模型提供方接入字段。不会修改 auth.json 或系统代理，也不会强制关闭 Codex。

接入后，在新的 Codex 会话核对是否生效；需要重启时，请在方便的时候自行重启。正在进行的请求不会被迁移，其他配置或程序也可能覆盖提供方接入字段。

v0.7.13：看清故障，再稳定选点

本机路由返回 502，不等于 OpenAI 返回 502。路由页区分本地代理不可达、DNS、TLS/证书、连接超时、上游 HTTP 和流式中断，并显示最近异常时间、阶段与实际出口是否核对。应用日志只保存分类与耗时等元数据，不保存对话、认证头或完整地址；同类事件限频，默认保留 3 天，可在设置调整。

稳定策略分别检查 ChatGPT 与 OpenAI API；默认以 ChatGPT 选点，显式开启 API Key 本地路由时改用 API 目标。基础通过、HTTP 可达但预期响应未验证、失败和过期分别显示。认证、权限和额度错误不直接处罚节点，200 或 401 都不代表模型流成功。

网络故障触发限频复查，保留健康节点，尊重手动固定与流量倍率预算。多个出口同时失败时先保留当前合预算出口复查，不反复切换；仅改变后续新连接，不重放模型请求。最多检查 10 个预算内候选，并发 2 个节点；不做带宽测速，基础探测仍消耗少量流量。

需要先在客户端启用稳定策略；本地路由和 Codex 接入仍各自确认、默认不自动开启。这里只说明版本能力，实际可用版本以下载区查询结果为准。

v0.7.15：地区、倍率与订阅余额

OpenAI 托管选点统一识别节点名称中的国家／地区、国旗和常见城市，按有版本记录的 OpenAI API 支持地区清单筛选。未知、多地区冲突和有子区域限制的名称不自动进入候选；生成、历史策略生效、运行时切换与手动固定使用相同判断。名称仅作为地区线索，不代替实际出口或账户可用性验证。

明确的 0.5x、×2、倍率:0.8 等标记直接作为流量倍率；有效手动覆盖优先，清空覆盖恢复自动识别。没有标记、冲突或非法倍率不当作 1×。成本页显示地区排除原因与倍率来源，质量优先和性价比模式仍各自保留。

旧候选池不足两个合格节点时，托管路径拒绝后续新请求并提示重新生成，不静默转回普通代理出口；普通代理组不受地区筛选影响。失效的手动固定保留选择意图，等待重新选点或恢复自动，不重放模型请求。

订阅卡片以剩余流量为主要数值。应用运行期间，每 5 分钟直接读取订阅响应的用量数据；先请求响应头，必要时 GET 获取元信息，余额为总额度减上传及下载。余额变化更新显示，不切换订阅、不新增配置版本、不触发代理重载；服务商缺少用量头或请求失败时保留上次采样并显示状态。此数据是服务商采样，不是本机流量估算。

实际已发布版本与六种平台安装包以下载区验证结果为准。

恢复原配置

使用「恢复原配置」时，客户端保留无关设置编辑。若其他程序已修改同一接入字段，会拒绝覆盖并保留备份；请核对页面显示的备份位置和冲突原因，不要直接删除备份。

关闭路由会先恢复接入；有请求进行中时会拒绝关闭。正常退出会尝试恢复 Codex 原配置；下次使用请核对并按需重新接入。服务启用状态会保留，异常退出后请以页面的接入与恢复提示为准。若原来的接入配置指向 CC Switch，恢复后仍依赖它原有的服务。

兼容，不等于无缝续接

兼容模式可以提供可观察的 HTTP/SSE 模型流入口；原生模式透传 WebSocket，不解析其中的模型事件。登录、遥测、远程控制等独立连接可能遵循不同的代理行为。

节点切换只用于后续新连接，不主动清空正常连接，也不自动重放模型请求。已经中断的数据流，无法靠换节点无缝续接。基础 API 返回 401 不能当成模型请求完整成功。

接入的数据边界

本地路由仅监听 127.0.0.1，固定转发支持的官方上游，不安装 TLS 解密证书，不将提示词或认证头写入日志或持久化文件，不跟随上游重定向。它不是公开网关，也不应通过端口映射暴露到互联网。

界面中的「已接入」描述配置状态，并不是对真实模型能力或长会话稳定性的保证。以当前安装版本的发布说明和实际验证为准。
