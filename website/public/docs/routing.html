Serylane / 文档 / 路由

按 AI 工具分流，地址由你补充。

路由使用代理核心内的域名规则。默认关闭，不再新增 Codex 接入；常见 AI 工具和自定义地址共用同一处理流程。安装包以下载区核验结果为准。

官网界面是只读示意，不代表实时连接，不操作本机应用、代理或配置。

常见工具与自定义地址

可勾选 OpenAI（ChatGPT / API）、Claude、Gemini（含 AI Studio / API）。默认草稿只选择 OpenAI。后台展开工具域名，和自定义条目统一校验、去重，界面可查看每个工具的具体范围。取消工具不会删除自定义条目。工具清单随版本更新，已应用名单保留原快照；重新保存并确认应用后才更新规则。

自定义支持 openai.com、*.openai.com，也可输入 https://*.openai.com/*。通配符只匹配子域，根域须另列。按域名处理全部 HTTPS/WSS 路径，不按加密 URL 路径拆分，不解密 TLS。共享登录、支付、客服、Google 公共资源以及语音 IP 不自动整域纳入；可按需补充明确域名。

全局开关与简洁配置页

v0.7.27 起，顶部「系统代理／TUN 模式」旁增加独立「路由」按钮，路由页也保留「开启／关闭路由」与「刷新状态」。两处共用启停状态；系统代理与 TUN 互斥，域名路由可与其中任一种配合，不切换网络接管方式。工具选择紧凑展示，域名范围和使用说明按需展开。

开启引导与真实生效状态

v0.7.29 增加配置引导与核心规则核对：尚未选择出口或编辑未保存时，顶部和页内入口引导到对应操作，不直接禁用；编辑改回原值可继续开启。不会自动替你选择出口。实际可下载版本以下载中心已公开安装包为准。

应用后核对核心的运行模式、规则总数及前置域名规则；通过后显示“已生效”。等待核心、出口失效、规则不一致和状态读取失败分别说明；核对异常时可刷新或重新应用。失败保留编辑，回退也会核验结果，不把提交成功等同于生效。

保存与应用分开

  1. 勾选工具、补充自定义地址，并明确选择当前订阅的出口策略组。
  2. 点击「保存草稿」，当前流量规则保持不变。
  3. 关闭状态点击任一「路由／开启路由」按钮并确认；已开启时点击「应用更改」确认新草稿。路由规则优先于本地规则、AI 规则和订阅规则；未匹配流量保留原规则。

只处理已经进入代理核心的连接，规则模式下生效。核心停止、全局或直连模式会显示未生效原因。切换订阅后目标组缺失时，匹配流量拒绝连接而不是静默直连；请重选出口或关闭域名路由。关闭只撤下此模块的覆盖规则，不删除其他规则。

暂时停用的能力

程序代理与增强 OpenAI 稳定灾备暂时隐藏并关闭，相关后台扫描、探测和自动选点不会运行。普通 AI 代理、自选节点和基础 Fallback 继续保留。性价比模式的倍率预算会进入有效候选过滤；预算内有效节点少于两个时拒绝托管路径新请求，不擅自扩大预算。

旧接入恢复

旧的模型中转不再新增接入或自动重启。已有 Serylane 接入记录只按所有权恢复原配置；外部程序修改同一字段时保留备份并显示冲突，页面仅保留旧接入恢复入口。旧设置文件保留，不把旧启用状态或具体路径静默转成新域名路由。

验证边界

节点切换只影响后续连接，不重放模型请求，不承诺中断数据流无缝续接。HTTP 401 只能证明接口可达，不代表模型会话或账户可用。TUN 平台支持范围不因本轮调整改变。

工具范围来源

自有域名归组参考 OpenAI 网络说明、Claude 服务域名说明和 Gemini API 文档。预置范围是 Serylane 的域名分流选择，不是上述厂商对完整可用性的承诺。
