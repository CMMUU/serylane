Serylane / 使用文档

从清楚了解开始。

Serylane 是管理你已有订阅与配置的独立桌面客户端，不提供代理节点或订阅服务。

快速开始路由接入与恢复校验与签名TUN 平台支持Windows TUN隐私与数据边界

快速开始

  1. 前往下载区域，选择系统与处理器架构，从项目的 GitHub 或 Gitee 发布页获取对应安装包。以发布页实际附件为准；没有对应附件时，不要下载其他架构的包代替。
  2. 根据对应版本的发布说明核对功能和平台要求；源码中的功能不代表已经进入当前安装包。
  3. 打开客户端，通过「订阅 → ＋ 添加订阅」添加自己的 Clash Meta / Mihomo YAML 订阅；本地 YAML 请在「配置」页面导入。订阅地址通常包含访问凭据，不要公开分享。
  4. 已有当前配置时，添加订阅默认不选用；只有勾选「添加后选用」才会替换当前配置。添加或选用不会自动启动代理，需要连接时再点击「启动」。使用系统代理或 TUN 前，先关闭其他代理客户端的同类接管功能，避免相互覆盖。
  5. Codex 本地路由是可选功能，不是日常代理使用的前置条件。没有需要时，保持默认关闭即可。

选择 Mac 芯片版本

macOS 安装包分为 Intel 芯片（x64） 与 Apple 芯片（M 系列，ARM64）。打开苹果菜单 →「关于本机」：显示 Intel 处理器时选 Intel 版；显示 Apple M 系列芯片时选 Apple 芯片版。不要仅凭 macOS 版本或机型年份猜测。

下载最新 Intel 芯片版 · 下载最新 Apple 芯片（M 系列）版。每次点击都会重新核对最新正式版；国内没有对应包时转到 GitHub 同版本包，不以另一种芯片的包代替。

理解订阅用量

订阅卡片展示服务商返回的上传、下载、总套餐流量与到期信息。这些数据是订阅响应中的采样，不是客户端实时统计的账单。

未提供的字段会明确标注。刷新失败时，客户端可能保留上一次成功采样；请同时留意更新时间与错误说明。缺失数据不等于零用量、无限套餐或永久有效。

选择适合的代理方式

  • 系统代理：供遵循系统代理设置的应用使用，不保证覆盖全部程序与连接协议。
  • 程序代理：为支持代理参数或环境变量的应用提供启动入口。不会强制关闭已有实例；旧实例可能忽略新启动参数，需要你方便时自行退出再启动。
  • 本地路由：仅对支持的 Codex 模型 API 提供独立入口，不代表接管整个 Codex 应用，也不保证登录、遥测或其他连接统一走该入口。

v0.7.17：TUN 启动与平台兼容

修复“预检完成却没有启动”的中断：权限和配置检查通过后，继续执行模式切换、启动和验收。预检通过不等于已接管网络；失败会保留具体阶段，切换后失败会尝试恢复原模式，并说明恢复结果。

macOS：首次使用需安装并在系统设置批准辅助服务。本版辅助服务协议更新为 v2；旧服务显示“需要更新”时，先停止代理，再在设置中主动更新辅助服务，并按提示核对系统授权。正在检查不表示授权丢失，短暂连接异常不会自动重新安装。Windows：继续使用管理员会话，不调用 macOS Helper，TUN 仍为实验性。Linux：目前未实现 TUN 网络接管，相关入口置灰；应用快选、程序代理与 TUN 是独立能力。

应用日志区分预检、配置校验及启动，不记录订阅正文或凭据。跨平台自动化不等于真实路由、DNS、休眠唤醒和长期网络验收。本节描述 v0.7.17 源码行为，安装包以实际发布版本为准。

Windows TUN：实验性功能

目前不将 Windows TUN 描述为已完成日常网络接管验收。管理员会话与内核进程生命周期已实现，但真实路由、DNS、停止和异常退出后的网络恢复仍需独立验收。

需要试用时，先保存工作并阅读当前版本发布说明。Windows 使用管理员会话：从托盘退出客户端后，自行选择「以管理员身份运行」。普通系统代理不要求管理员会话。

停止或退出时，客户端会按自身状态尝试恢复网络设置；关闭主窗口通常只是隐藏到托盘。系统代理恢复会核对控制权，避免覆盖后来由其他客户端设置的代理。不要同时开启多个客户端的系统代理或 TUN。

如果恢复失败，不要反复切换多个接管工具。先记录当前错误与状态，停止相关接管，再核对系统代理和 DNS 设置。遇到不明确的网络状态时，保留日志并通过项目问题追踪反馈，分享前删除订阅链接、令牌和个人信息。

0.7.7 起：启动恢复与应用日志

主「启动」按钮使用当前保存的网络模式，不再强制切换为系统代理。「登录时启动」「开机静默启动」和「恢复上次运行状态」分别设置；静默仅影响登录自动启动，手动打开仍显示主窗口。恢复沿用保存的配置和代理方式，遇到权限不足或其他代理占用时暂停，不会自动提权或强行接管。

旧版没有保存运行意图时，首次升级保持停止。在新版成功启动一次后，后续登录才有明确的恢复依据。在任务管理器中禁用的自启动项不会仅因迁移或调整静默选项而重新启用。

「日志」中的应用日志默认保留 3 天，可在设置改为 1–90 天。采用有容量上限的紧凑存储并合并重复事件，查看时格式化展示；达到容量上限时可能提前移除最旧记录。日志不记录对话正文、订阅凭据或请求头。

v0.7.8：启动模式与状态保持

设置提供三种明确的启动模式：不随系统启动、登录后后台恢复上次状态、登录后打开窗口并恢复。上次开启则恢复原模式和配置，上次停止则保持停止；关闭主窗口只是隐藏，托盘退出保留原启停记录。

系统登录项核对区分登记、禁用和未知状态。临时网络故障采用退避等待，用户停止可取消等待或清除已暂停恢复的开启记录；权限和代理所有权冲突不自动接管。

macOS 双行速率托盘的正常字体和备用路径均从应用同一份 S 图标生成，不再显示旧 M；菜单栏图形采用系统模板着色。对应功能随 v0.7.8 安装包交付，当前可用版本以下载区实时核对结果为准。

v0.7.9：更清晰的 macOS 双行网速

保留应用同源 S 图标，右侧上下行数字改用原生双行文字。等宽数字、独立的数值与单位列、固定宽度，让速率变化时更容易扫读，旁边的菜单栏图标不再随位数伸缩。

数字使用 9.5pt Medium 字号，箭头与单位较小；根据实际按钮高度完整排布两行，跟随系统亮暗外观。菜单栏紧凑显示 K/M/G 等单位，悬停查看 KiB/s、MiB/s 等完整速率。关闭流量显示后恢复纯 S 图标，重新开启恢复双行。

此改进仅调整 macOS 显示，不修改启动模式、代理或路由设置。对应功能随 v0.7.9 安装包交付，当前可用版本仍以下载区实时核对结果为准。

v0.7.16：三平台应用快选与更新跟随

「程序代理」从已安装应用清单搜索选择，保留普通文件入口。Windows 以 MSIX / Store 包系列和应用 ID 绑定；macOS 选择完整 .app，以 Bundle ID、原选位置和可用签名身份绑定；Linux 读取 XDG .desktop，按 Desktop File ID 和来源关联。正常更新后重新解析，不凭最高版本目录替换应用，也不负责下载或安装更新。

缓存清单立即可搜索，后台单次刷新不锁编辑、不丢草稿与焦点；普通打开复用 30 秒缓存，「重新扫描」主动强刷。失败保留旧清单并显示状态；点击启动仍重新核对身份和入口，展示缓存不作为启动依据。

macOS 使用 NSWorkspace 原生启动新实例并传入代理环境和参数；已有实例请先自行退出。GUI 使用系统原生工作目录，旧自定义目录保留，需明确选择默认目录后保存；未签名或 ad-hoc 应用移动后需重新关联。Linux 普通入口按 Exec 独立参数和 Path 启动，支持手选可执行文件或 AppImage；D-Bus、Terminal、Flatpak/Snap 及包装启动器显示「启动方式待适配」。Windows 普通 .exe 及现有代理参数保持兼容。

清单升级 v3 前保留旧 v1/v2 原始备份。未安装、读取失败、需要重新关联、已有实例及启动结果待确认分别说明下一步。保存不启动应用，不切换系统代理／TUN或改全局环境。启动成功不等于所有流量已走代理，真实应用登录和长会话另行验证。实际发行版本以下载区为准；详细说明与迁移。

v0.7.11：更快开启，更清楚地了解状态

系统代理在本地接管完成后即可使用，网络检查随后在后台执行。界面分别显示代理已开启、正在检查和部分检测未通过；OpenAI 接口可达不等于模型会话已验证。

已运行的本地端口模式与系统代理模式之间切换时，不主动重启核心。配置、端口、系统设置读回及失败恢复仍保留；TUN 继续走完整权限流程。错误提示提供下一步操作与技术详情，不再只有一长串错误码。

以上功能随 v0.7.11 安装包交付，下载区查询实际公开版本。真实网络、登录和重启另行验收。

v0.7.10：静默启动与自主选点

修正旧设置没有静默字段时仍弹出主页的问题。新设置和缺失该字段的旧设置默认登录后仅在托盘运行，不需要先保存一次设置；明确选择“打开窗口”的偏好保持不变。重复自启动不唤起主页，主动点击托盘或打开应用才显示窗口。需开启登录启动；代理仍按已保存的启停状态与原模式恢复。

代理页支持独立选择普通节点和 OpenAI 灾备候选，概览显示实际选用节点与脱敏详情。手动固定 OpenAI 节点后自动切换暂停，可明确恢复自动；选点不主动关闭既有连接。

“成本与性价比”支持按服务商信息填写流量倍率、设置上限，并在质量接近时优选低倍率节点。未知倍率默认不参与；无符合预算的健康节点时拒绝后续新请求。手动固定仍优先，未知或超预算选择需要确认。省流筛选跳过大流量带宽测试，但基础探测仍耗流量；实际计费以服务商为准。

以上能力随 v0.7.10 安装包交付，请先在下载区核对实际发布版本。真实登录/重启及模型流稳定性不以合成界面或单元测试代替验收。
