清楚区分数据的去向。

官网、发布渠道和你电脑上的代理客户端是不同的系统。浏览官网并不等于启动代理，也不会自动接入 Codex。

这个官网

本站提供静态产品信息与文档，没有账号系统，不要求提交订阅地址、认证令牌或本地配置。系统和架构选择、菜单以及常见问题的展开改变当前网页显示。首页还会向本站接口查询公开发布信息；下载入口由服务器核对最新正式版、安装包元数据与渠道可用性，再跳转下载，不要求提供个人配置。

本站不会连接你电脑上的代理端口、启动本地服务或修改系统设置。产品界面标有「界面示意 · 非实时状态」，不是实时连接检测。

网站托管与内容分发服务可能为交付页面和安全防护处理 IP 地址、请求时间、浏览器信息等基础访问数据；这不等于桌面客户端上传订阅或模型请求。

外部链接与下载

本站下载服务会向 GitHub、Gitee 与香港下载中心查询公开发布元数据；不会转发浏览器的 Cookie、授权头或完整访问请求。国内优先下载只选择同版本、同架构、同格式的包，无法确认最新正式版时返回错误，不自动转向旧版本。点击下载并跳转到香港文件域、GitHub、Gitee，或点击其他外部链接后，其访问数据由对应平台按自身规则处理。请在项目正式发布页核对安装包，不向陌生站点提交订阅和令牌。

桌面客户端与本地路由

订阅和代理配置由你自行提供。订阅地址可能包含访问凭据；分享截图、日志或问题报告前，请核对并删除令牌、完整订阅链接和个人信息。

可选路由仅在你明确启用后工作，接入 Codex 也需要单独确认。当前路由实现不将提示词或认证头写入日志或持久化文件，接入前备份配置，恢复时检查其他程序是否修改了同一字段。具体实现与当前版本边界见路由文档。

反馈问题

可通过项目问题追踪反馈。公开问题页可被其他人阅读，请不要粘贴密码、私钥、订阅凭据或未脱敏的配置。需要报告安全问题时，先查看仓库是否提供合适的私密报告渠道，不要在公开页面披露敏感细节。
