更新日志校验与签名说明

开始前，你可能想知道。

Codex 更新后，程序代理里的旧路径失效怎么办？

v0.7.12 起，Windows 程序代理可从已安装 MSIX / Store 应用选择，保存应用身份并自动跟随安装版本。旧条目点「重新关联」后保留代理方式和参数；便携软件继续选择 .exe。查看应用绑定说明；实际可用版本以下载区查询为准。

开启系统代理时，还需要等待网络检查吗？

v0.7.11 起，本地接管完成后即可使用，外网检查在后台继续。页面会分别显示代理开关和联网状态。查看启动与提示说明；实际可用版本以下载区查询为准。

登录后会弹出主页吗？

选择“登录后后台恢复上次状态”即可只在托盘运行。v0.7.10 修正旧设置缺少静默选项时仍弹窗的问题，查看静默启动与选点说明。

是否提供代理节点或订阅？

没有。你需要自行准备订阅或本地配置。

安装后会自动接入 Codex 吗？

不会。路由默认关闭，启用与接入需要分别操作。

Windows TUN 可以直接日常使用吗？

目前为实验性功能，使用前请阅读限制与恢复说明。
