03 / BEFORE YOU START

A few clear
answers.

Are nodes or subscriptions included?

No. Serylane is a desktop client, not a proxy service. Bring your own subscription or local Mihomo configuration.

Will it enable routing or connect Codex automatically?

No. Domain routing is optional and off by default. Choose tools and an exit, save your draft, then explicitly apply it. New Codex attachment and application-based proxying are currently disabled. Read the routing guide

Is TUN ready on every platform?

Windows TUN is experimental and requires an administrator session. TUN is not ready in the macOS compatibility packages, and is not implemented on Linux. Switching nodes does not resume an interrupted stream. Platform limitations
